01

What this document covers

One RE model that serves every RE audience in myUNO.
Audience 1 — demand

Buyer · Investor · Tenant

Searches, compares, requests viewings, places deposits, signs contracts, moves in / takes ownership.

Audience 2 — supply

Owner · Landlord

Lists, prices, onboards MC, tracks income, approves maintenance, signs statements, manages tax.

Audience 3 — operator

Agent · Developer · MC

Imports inventory, qualifies leads, schedules viewings, reserves units, runs pipelines, manages staff.

Principle

One property · many contexts.

The same property row can simultaneously be a resale listing, a rental listing, and a managed unit with an owner statement — with three different call-to-actions on the same detail screen, gated by viewer's role stack.

02

Canonical taxonomy

Every RE entity classified along 4 axes. Code must reference these constants, never strings.

Axis 1 · Property class

Residential

Condo · villa · townhouse · apartment · penthouse · studio

Commercial

Retail · office · hotel/hostel · F&B · mixed-use

Land

Chanote · Nor Sor 3 · leasehold plot · agricultural

Special

Branded residence · serviced apartment · co-living · fractional

Axis 2 · Listing intent

Sale · resale

Secondary market. Freehold / leasehold / foreign quota tracking.

Sale · off-plan

Developer inventory. Phase & construction progress. Payment plan.

Rent · long-term

6m+ lease. Tenant screening. Yearly.

Rent · short-term

STR — daily/weekly. OTA sync. Yield mode.

Axis 3 · Tenure & ownership

Freehold (foreign quota)

Condo ≤ 49% quota. Chanote title. Foreign remittance letter (TT3).

Leasehold 30+30+30

Villa / land. Registered at Land Dept. Protected structure docs.

Company (Thai Co Ltd)

Thai nominee-free structure. Licensed counsel required.

Axis 4 · Management mode

Self-managed

Owner runs it. Owner is the responder for leads & maintenance.

MC-managed

Assigned to a Management Company. MC fee schedule active. Owner sees statements.

Developer-pool

Part of a developer rental pool guarantee. Fixed return or shared revenue.

Data model

Supabase tables. Nouns. Everything else is a view.

amount · payment_plan · conditions[] ├─ expires_at └─ state: draft | submitted | countered | accepted | rejected | withdrawn reservations // off-plan deposits ├─ lead_id · unit_id (property) ├─ deposit_amount · due_at ├─ spa_due_date // Sale & Purchase Agreement └─ state: holding | confirmed | converted_to_sale | expired rentals // active rental contracts ├─ listing_id · tenant_id → persons ├─ start · end · rent · deposit · utilities ├─ renewal_option └─ state: draft | active | ending_soon | ended | terminated statements // owner statement per period ├─ property_id · owner_id · period(month) ├─ gross_revenue · mc_fee · platform_fee · net_payout ├─ bookings[] · expenses[] └─ state: draft | issued | signed | paid maintenance_tickets // attached to properties ├─ property_id · reporter · assignee · priority ├─ cost_estimate · cost_actual └─ state: new | triaged | scheduled | in_progress | done | invoiced
Why one properties table

A single row is a villa that is simultaneously managed by an MC, listed for short-term rental, and flagged by its owner as "considering sale 2027". Separate tables per intent duplicate the same building.

Buyer / Investor / Tenant screens

Lives under /app/invest/property, /app/invest/offplan, /app/live/rental.

01 · RE Hub

/app/invest

Cluster-coloured entry. Three tiles: Resale, Off-plan, Rent. Below: Saved searches · Recent viewings · Your offers. For investors: Portfolio summary.

02 · Property search

/app/invest/property/search
  • Controls: intent toggle · district · class · subtype · price range · area · bedrooms · keyword · tenure
  • Secondary: developer · completion date · pool/sea view · furnished · pet friendly
  • Views: list · grid · map (clustered) · split
  • Save search — name + alert frequency
  • Compare tray — up to 4 properties

03 · Property detail

/app/invest/property/:id
  • Hero: media gallery · price · key specs (beds · area · tenure) · status badge
  • Tabs: Overview · Layout · Location · Financial (yield · mortgage sim) · Legal · Similar
  • CTA stack (role-aware): Book viewing · Request info · Make offer · Save · Compare · Share
  • Trust panel: title type · developer licence · agent licence · last verified
  • Agent card: one assigned agent · response time · languages · book slot

04 · Off-plan project

/app/invest/offplan/:id
  • Hero: rendering · completion % · phase · delivery date
  • Unit picker: interactive floor plan / stacking plan · available vs reserved · price per sqm
  • Payment plan: installment timeline with due dates
  • Developer tab: track record · past projects · financials (if public)
  • Rental pool: guarantee terms · projected yield
  • CTA: Reserve unit (deposit) · Request call · Download brochure

05 · Map view

/app/invest/property/map

Full-screen map · clustered markers · price chips · filter sheet · drawer with selected property preview. District boundaries overlay. "Search this area" on pan.

06 · My shortlist · Compare

/app/invest/my/shortlist

Saved properties · comparison matrix (price/sqm, yield, tenure, timeline) · notes · share with agent.

07 · Viewings

/app/invest/my/viewings

Upcoming (calendar) · Past (with notes + agent rating). One-tap reschedule. Video-viewing toggle.

08 · Offers & reservations

/app/invest/my/offers

State pipeline per offer: Draft · Submitted · Countered · Accepted · Expired. For off-plan: Reservation state + SPA due date + installment schedule.

09 · Transaction room

/app/invest/tx/:id
  • Checklist: KYC · foreign remittance · due diligence report · SPA · TT3 · Land Dept appointment
  • Documents vault with version history & signatures
  • Counter-party card: agent · lawyer · counter-party
  • Messages thread
  • Audit trail: every step timestamped & anchored to ledger

10 · Rental search & application

/app/live/rental

Long-term rental search · application form · screening docs · lease template preview.

F2 · Viewing request

Slot picker (agent availability) · mode (onsite / video) · attendees · optional preferred language · contact preference (chat / call / WhatsApp). Produces viewings row + leads row in viewing stage.

F3 · Make offer

Amount · financing (cash / mortgage / staged) · conditions (inspection · subject-to · closing date) · expiry. Generates draft offers row + notifies seller-side agent. Legal assistant AI offers template language.

F4 · Off-plan reservation + deposit

Select unit → KYC check → deposit amount (fixed by project) → payment method → electronic signature of reservation form. Holds unit. Timer to SPA signing. Refund policy inline.

F5 · Long-term rental application

Tenant screening: ID · employment / business · references · pets · duration · preferred start. Owner approval CTA. Lease drafted auto when approved.

F6 · Lead intake (buyer)

Budget · timeline · purpose (self-use / investment / rental yield target) · preferred districts · must-haves vs nice-to-haves. AI-suggests saved search.

F7 · Add project (developer)

Project meta → phases → unit mix generator (types × count) → renderings → amenities → payment plan template → rental pool terms → publish.

F8 · Maintenance ticket (owner · guest · MC)

Property auto-selected · category · priority · photos · video · access window. Cost estimate thread. Owner approval above threshold.

F9 · Commission split configurator (agent)

Deal size → platform fee → agency → lead agent → sub-agent referral → overrides. Saved as commission template.

11

State machines

Canonical transitions. UI must never allow invalid jumps.

Listing lifecycle

draft ─ publish ─→ active ─ archive ─→ off_market └─ deal-in-progress ─→ under_offer ├─ close ─→ sold | rented └─ fall-through ─→ active

Lead stages

new → qualified → viewing → offer → deposit → signed → closed_won └──→ closed_lost (at any stage)

Reservation (off-plan)

holding → confirmed → converted_to_sale └─ expired (timeout) → expired

Offer

draft → submitted → countered ⇄ submitted ├─ accept → accepted ├─ reject → rejected └─ withdraw → withdrawn

Rental contract

draft → active → ending_soon → ended └─ terminate → terminated

Trust, compliance, inline markers

Trust is UI, not a footer. Every screen earns its markers.
Identity

KYC levels

L0 browse · L1 enquire · L2 reserve/offer · L3 sign/transfer. Level displayed on Me.

Title

Title type badge

Freehold (foreign quota X/Y) · Leasehold (years remaining) · Thai Co — always on listing card & detail.

Licence

Agent & developer licence

Broker-licence ref shown on every listing + agent profile. Developer permit + construction licence on project page.

Money

Escrow markers

Deposits held via named escrow counterparty — inline on the pay screen with tx id.

Audit

Ledger anchor

Every money movement links to a ledger_entries row. "View audit" from any tx/statement.

Privacy

PDPA consents

Explicit per-purpose consents. Revocation in /me/consents affects downstream AI & agent access live.

# AGENTS.md

## Cursor Cloud specific instructions

### Overview

myUNO is a React 18 + TypeScript + Vite SPA ("SuperApp for Phuket"). The backend is fully hosted on Supabase Cloud — there is **no local database or backend server to run**. The `.env` file already contains the required Supabase credentials (`VITE_SUPABASE_URL`, `VITE_SUPABASE_PUBLISHABLE_KEY`, `VITE_SUPABASE_PROJECT_ID`).

### Running the app

- **Dev server:** `npm run dev` — starts Vite on port **8080** (not the default 5173; configured in `vite.config.ts`).
- **Build:** `npm run build`
- **Lint:** `npm run lint` — runs ESLint. The codebase has many pre-existing `@typescript-eslint/no-explicit-any` warnings; these are expected.

### Testing

- **Unit tests:** `npx vitest` (Vitest, config in `vitest` section or default)
- **E2E tests:** `npx playwright test` (Playwright, tests in `e2e/tests/`)
- Playwright may require `npx playwright install chromium` on first run.

### Key caveats

- The landing page shows a "Coming Soon" page. Clicking "Sign In" navigates to `/auth` for login/registration.
- The `src/integrations/` directory is auto-generated by Supabase — do NOT edit files there.
- The `supabase/migrations/` directory contains 480+ SQL migrations — do NOT edit those.
- Edge Functions live in `supabase/functions/` (Deno runtime); they are deployed to Supabase Cloud, not run locally.
- The package manager is **npm** (lockfile: `package-lock.json`). A `bun.lock` also exists but npm is canonical.

# Сборка и CI (P1-R1)

## Текущие предупреждения сборки

- **Tailwind:** предупреждения по классам `ease-*`, синтаксис CSS — при правке соответствующих компонентов заменять на рекомендуемые классы или поправить конфиг Tailwind.
- **PWA / chunk size:** Vite может предупреждать о размере чанков; при добавлении тяжёлых зависимостей следить за размером и при необходимости разбивать lazy-импорты.

## Рекомендации для CI

1. **Проверка сборки:** в CI выполнять `npm run build`; падение при ошибках сборки уже обеспечивается (exit code).
2. **Лимит размера чанков (опционально):** добавить шаг, проверяющий размер артефактов в `dist/assets/*.js` (например, fail если какой-либо файл > 500 KB без явного исключения). Можно реализовать скриптом в `scripts/` и вызывать из CI.
3. **Чистота сборки:** со временем включить в CI проверку на отсутствие определённых предупреждений (например, парсить вывод `npm run build` и падать при появлении новых строк с "warning" в ключевых категориях).

Подробности аудита — в `docs/audits/TECHNICAL_AUDIT_REPORT.md` (P1-R1).

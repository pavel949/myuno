# Google Maps API Key — настройки в Google Cloud Console

Для myUNO нужны: **Maps JavaScript API**, **Geocoding API**, **Places API**. Ниже — как проверить настройки ключа.

## API restrictions (ограничения по API)

- Должен быть выбран режим **«Restrict key»** и в списке включены:
  - **Maps JavaScript API**
  - **Geocoding API**
  - **Places API** (и при необходимости **Places API (New)**)
- Остальные API лучше не включать (минимальные права).

У вас в консоли уже включены Geocoding API, Maps JavaScript API, Places API и Places API (New) — этого достаточно.

## Website restrictions (ограничения по сайтам)

Ключ используется в браузере: запросы идут с **HTTP referrer** страницы (например `https://myuno.app` или `http://localhost:5173`). Если ограничения по сайтам настроены неверно, карты и геокодинг не работают (часто без явной ошибки в UI).

### Вариант A: ключ без ограничений по сайтам

- В блоке «Website restrictions» **ничего не добавлено** или список пустой → ключ принимается с любого сайта.
- Подходит для разработки; в проде лучше ограничить ключ (см. вариант B).

### Вариант B: ограничить ключ своими доменами (рекомендуется для продакшена)

В **Website restrictions** добавьте **HTTP referrers** и включите их (чтобы они реально применялись):

| Referrer | Назначение |
|----------|------------|
| `https://myuno.app/*` | Продакшен, корень |
| `https://www.myuno.app/*` | Продакшен с www |
| `https://*.myuno.app/*` | Любые поддомены (например app.myuno.app) |
| `http://localhost:*` | Локальная разработка (любой порт) |
| `http://localhost:5173/*` | Точный порт Vite, если нужен |
| `https://*.vercel.app/*` | Превью-деплои на Vercel (если используете) |

Важно:

- Формат именно **HTTP referrer**: с протоколом и, при необходимости, с `/*` в конце.
- Без `/*` ограничение может не сработать для путей вида `/map`, `/admin` и т.д.
- После сохранения изменений может потребоваться **до 5 минут**, прежде чем настройки начнут действовать.

### Если в консоли есть чекбоксы у каждого referrer

- **Снятый чекбокс** обычно значит, что эта запись **не участвует** в ограничении (не активна).
- Если все чекбоксы сняты при непустом списке, возможны два варианта в зависимости от интерфейса:
  - либо ограничения не применяются (ключ принимается отовсюду),
  - либо ключ не принимается ни с одного сайта.
- Чтобы ограничение по домену работало: нужная строка должна быть в списке **и** отмечена (если в UI есть чекбоксы).

Рекомендация: для продакшена добавьте перечисленные выше referrers и убедитесь, что они **активны** (включены/отмечены), тогда ключ будет работать и с `https://myuno.app`, и с `http://localhost:*`.

## Проверка из приложения

1. Админка → **Системные настройки** (Control) → карточка **Google Maps**.
2. Нажмите **«Проверить геокодинг»**.
3. Должен появиться тост и либо «Геокодинг работает», либо сообщение об ошибке (например `REQUEST_DENIED` или таймаут).

При `REQUEST_DENIED` чаще всего причина — ограничения по API или по HTTP referrer (в т.ч. не добавлен localhost или домен продакшена).

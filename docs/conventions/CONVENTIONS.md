# Coding Conventions

## File Naming

| Type | Pattern | Example |
|------|---------|---------|
| Page component | `XxxPage.tsx` or `Xxx.tsx` | `RestaurantsPage.tsx`, `Discover.tsx` |
| Hook | `useXxx.ts` | `useRestaurants.ts` |
| Context | `XxxContext.tsx` | `AuthContext.tsx` |
| Filter config | `XxxFilters.ts` | `RestaurantFilters.ts` |
| Type definitions | `xxx.ts` | `orders.ts` |
| Utility | `xxxUtils.ts` or `xxx.ts` | `orderUtils.ts` |
| Edge function | `kebab-case/index.ts` | `create-checkout/index.ts` |

## Barrel Exports

Each component folder should have an `index.ts` that re-exports public API:

```typescript
// src/components/filters/index.ts
export { UniversalFilter } from './UniversalFilter';
export type { FilterConfig } from './UniversalFilter';
```

## Localization

Use `useLanguage()` context for all user-facing text:

```tsx
const { isRu } = useLanguage();

// Simple text
<h1>{isRu ? 'Рестораны' : 'Restaurants'}</h1>

// Database fields
<p>{isRu ? item.name_ru : item.name_en}</p>
```

**Do NOT** use i18n libraries. The bilingual pattern is consistent across the entire codebase.

## UI Components

- **Only** use components from `shadcn/ui` (in `src/components/ui/`)
- Import Radix primitives via shadcn wrappers, **never** directly from `@radix-ui/*`
- Icons: use `lucide-react` only
- Animations: use `framer-motion`

## Styling

- Use Tailwind CSS with **semantic tokens** from the design system
- ❌ `text-white`, `bg-blue-500`, `text-[#333]` — raw colors
- ✅ `text-foreground`, `bg-primary`, `text-muted-foreground` — semantic tokens
- All colors must be HSL and defined in `index.css` / `tailwind.config.ts`
- Use `cn()` utility from `src/lib/utils.ts` for conditional classes

## Data Fetching

- Use TanStack React Query via custom hooks
- Generic helpers: `useSupabaseQuery()`, `useSupabaseCRUD()`
- Each vertical has its own data hook: `useRestaurants()`, `useYachts()`, etc.

## Database Patterns

### Vertical Entity Tables

Each vertical has a table with standard fields:
- `id` (UUID, PK)
- `name_en`, `name_ru` (bilingual names)
- `description_en`, `description_ru`
- `is_active` (soft delete / visibility)
- `is_featured` (homepage promotion)
- `provider_id` (FK to `providers`)
- `created_at`, `updated_at`
- `approval_status` (moderation: `pending` | `approved` | `rejected`)
- `images` (string array of URLs)

### Vertical ID Convention

Use **singular** form internally: `property`, `yacht`, `vehicle`
Use **plural** form in URLs: `/properties`, `/yachts`, `/transport`
See `src/lib/verticals.ts` for the canonical mapping.

## Error Handling

Use `createErrorHandler()` from `src/lib/errorHandler.ts`:

```typescript
const errorLog = createErrorHandler('ComponentName');
errorLog.silent(error, 'operation_name'); // logs without crashing
```

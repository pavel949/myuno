# Сборка и CI (P1-R1)

## Текущие предупреждения сборки

- **Tailwind:** предупреждения по классам `ease-*`, синтаксис CSS — при правке соответствующих компонентов заменять на рекомендуемые классы или поправить конфиг Tailwind.
- **PWA / chunk size:** Vite может предупреждать о размере чанков; при добавлении тяжёлых зависимостей следить за размером и при необходимости разбивать lazy-импорты.

## Рекомендации для CI

1. **Проверка сборки:** в CI выполнять `npm run build`; падение при ошибках сборки уже обеспечивается (exit code).
2. **Лимит размера чанков (опционально):** добавить шаг, проверяющий размер артефактов в `dist/assets/*.js` (например, fail если какой-либо файл > 500 KB без явного исключения). Можно реализовать скриптом в `scripts/` и вызывать из CI.
3. **Чистота сборки:** со временем включить в CI проверку на отсутствие определённых предупреждений (например, парсить вывод `npm run build` и падать при появлении новых строк с "warning" в ключевых категориях).

Подробности аудита — в `docs/TECHNICAL_AUDIT_REPORT.md` (P1-R1).

## Отдельный облегчённый веб-артефакт (opt-in)

`npm run build` и конфигурация хостинга не меняются. На POSIX-раннере
после чистой завершённой сборки, которую больше никто не меняет:

```bash
# MYUNO_PRIVATE_ROOT: закрытая директория ВНЕ каталога репозитория, доступная
# только UID процесса; должно быть согласовано место её долговременного хранения.
# MYUNO_STAGE_ROOT: существующая папка для временных публичных артефактов.
install -d -m 700 "$MYUNO_PRIVATE_ROOT"
npm run stage:web -- dist "$MYUNO_STAGE_ROOT/web-$BUILD_ID" "$MYUNO_PRIVATE_ROOT/$BUILD_ID"
node --test scripts/stage-web-artifact.test.mjs
```

Оба конечных каталога должны быть новыми, непересекающимися, с существующими
родительскими каталогами. `dist` не переписывается. Сначала сохраняются точные
`*.js.map` (в том числе карты Workbox, `.mjs.map` и `.cjs.map`) и приватный
`artifact-integrity.json` с отпечатком сборки и SHA-256 каждой карты и каждого
публичного файла. Только после успешной проверки копируется публичный набор
без JS-карт; все оставшиеся байты, включая PWA, сохраняются. Неподходящие права,
пересечения, ссылки, рассогласованные файлы или использование карты в коде
service worker блокируют выдачу пакета. Никакой сетевой операции скрипт не делает.

**Перед отдельным выпуском:** сверить SHA в `version.json` с одобренным коммитом;
закрепить архив, его отпечаток и политику хранения в закрытом хранилище; убедиться,
что Sentry расшифровывает контрольное событие того же артефакта (не только с тем же
номером версии). Затем проверить маршруты, обновление и офлайн-режим PWA и ответы
на URL карт в непроизводственном окружении с синтетическими данными. Само наличие
закрытых файлов на диске не доказывает загрузку или расшифровку в Sentry. Не
публиковать приватный каталог, исходный `dist` или их общий родительский каталог.
Если целевой хостинг не позволяет явно выбрать отдельный публичный артефакт,
**не включать этот режим**. Откат: предыдущая проверенная веб-сборка; данные,
Edge Functions и настройки диагностики этот этап не меняет.

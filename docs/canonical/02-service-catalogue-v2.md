> **Статус:** эталонный (target spec). Источник истины для продуктовых, UX и контентных решений.

> **Runtime на 2026-05-20:** 18 категорий (после расширения Halal & Faith, май 2026) · ~80 активных entries в `src/lib/catalog/taxonomy.ts` (статический SSOT) + динамические из DB. Кумулятивный счёт услуг в §18 даёт 227, не 230 — расхождение унаследовано из v1, спецификация остаётся target до сверки следующей итерации.
> **Связанные документы:** `01-segmentation-framework.md` (сегментация), `03-tone-of-voice.md` (голос).

## 0 · Как читать этот документ

Каждая услуга описана шестью полями:

| Поле | Значение |
|---|---|
| **Название** | то, как услуга показывается клиенту |
| **Описание** | одно-два предложения, что именно делаем |
| **Монетизация** | модель и сумма (комиссия / подписка / фикс) |
| **Для кого** | ключевые персоны (по framework) |
| **Кластер** | код ситуации (A–J, см. раздел 5 framework) |
| **Lifecycle / Role** | теги для AI-роутинга и фильтров |

**Легенда кодов:**

- **Lifecycle:** `scout` · `tourist` · `snowbird` · `nomad` · `settler` · `resident` · `absentee` · `returnee` · `all` (применимо ко всем)
- **Role:** `consumer` · `resident-user` · `investor-passive` · `investor-active` · `operator` · `provider` · `all`
- **Cluster:** `A` Arrival · `B` Extension · `C` Settlement · `D` Investment Consideration · `E` Transaction · `F` Operations · `G` Legal/Compliance · `H` Emergency · `I` Lifestyle · `J` Exit

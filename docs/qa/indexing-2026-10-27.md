# myuno.app indexing repair — 27 October 2026

Scope: pavel949/myuno only. Base 046663d895ccdc4beedacaa436e6e7044938895b (PR197). This is a technical crawl/canonical audit, not confirmation of Google's index.

## Observed production evidence

- Both Google notices dated 26 October were read from Gmail: first reports alternate canonical + duplicate without selected canonical; second reports alternate canonical in sitemap. Neither provides affected URL examples. They precede PR197 and do not establish that PR197 caused them.
- Production raw HTML contains PR197's exact commit SHA and index-DiCbKHjd.js. HTTP 200 pages `/`, `/property`, `/property/search`, `/newbuilds` share the same static HTML and a homepage canonical. No X-Robots-Tag was returned. robots.txt permits public property paths.
- Rendered `/property/search` has one correct canonical `https://www.myuno.app/property/search`, no noindex, document language ru. Loading `/property/search?lang=en` in the same browser still renders Russian H1 and language ru; LanguageContext reads localStorage/browser language, never URL lang.
- Rendered `/property/projects` navigates to `/property/offplan`, whose canonical is `/property/offplan`. `/property` and `/stays/search` redirect to `/property/search` in the actual router. Other confirmed aliases in sitemap: `/property/invest` → `/invest`, `/newbuilds/projects` → `/property/offplan`, `/newbuilds/developers` → `/property/developers`.
- `/guides/buying-property-thailand` renders Page not found; no `/guides/*` route exists. sitemap-pillars.xml contains ten placeholders.
- HTTP and HTTPS apex requests reach `https://www.myuno.app/`. Vercel config had the reverse host redirect, plus redirects incorrectly taking the real `/property/offplan` routes to `/newbuilds`. Live hosting is Lovable: the Vercel correction reconciles configuration and is not evidence that these rules ran in production.
- Dynamic listing sitemap endpoints were already removed on 25 October because their generator does not exist. This repair does not re-add nonexistent endpoints or invent public inventory IDs.

- The live offplan catalogue renders 36 projects but zero anchors to `/property/offplan/:id`. OffplanProjectCard navigates with a div click handler. Add an actual title Link so Google can discover the detail URL without clicking UI. Inventory values are not validated by this observation.

## Repair contract

- Remove homepage canonical from shared raw SPA shell. Google explicitly recommends omitting a raw canonical when JavaScript must set a different route canonical: https://developers.google.com/search/docs/crawling-indexing/javascript/javascript-seo-basics
- Keep existing page-specific canonicals, add missing resale/developer catalogue metadata, and remove marked fallback descriptions when landing metadata mounts.
- One current URL per page. Language remains an unchanged user preference. Do not advertise ignored `?lang` URLs via hreflang in SEOHead, landing heads or sitemaps. Stored translated copy remains intact. Restore language URL annotations only with deterministic routing, same-language canonicals, reciprocal annotations and supported content. This is consolidation of current duplicates, not completion of multilingual SEO.
- Filters, tracking, hashes and ignored lang parameters consolidate to page path as before. Do not noindex useful property pages to suppress duplicates.
- Remove six confirmed aliases from static sitemap. Remove ten nonexistent guide entries and omit their sitemap from index. Keep public `/property/search`, `/property/offplan`, `/property/resale`, `/property/developers` and `/newbuilds`.
- Mark real NotFound rendering noindex; SPA server still returns HTTP200 for unknown paths. Proper server404/SSR/prerender remains a separate hosting improvement.
- Align Vercel host and legacy offplan redirects with existing production host and actual application routes. Generator must not recreate false hreflang or apex-host URLs.

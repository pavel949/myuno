## 2. Methodology

| Tool | Purpose | Result |
|---|---|---|
| `knip` (via npx) | Unused files / exports / deps in one pass | 339 issues found (141 real in `src/`) |
| `depcheck` (via npx) | Second-opinion dep analysis | 6 unused deps confirmed (matches knip) |

| `npm run build` | Bundle build health | ✅ Pass after every phase |
| `npm run lint` | ESLint / React-hooks rules | No new errors introduced |

**False-positive handling:** knip cannot follow:
- Dynamic lazy imports via `React.lazy(() => import(...))` wrapped in barrel modules (`src/components/layout/pageRegistry.ts`);
- Deno-style `npm:`/`jsr:` imports inside `supabase/functions/`;
- Config-referenced entry points (e.g. `src/sw.ts` referenced by `vite-plugin-pwa`).

Every deletion was sanity-checked with a second grep before removal.

## 6. Bundle analysis — caveat

Production `vite build` in this environment produces suspicious output:

| Chunk | Size |
|---|---:|
| `vendor-radix-*.js` | 141.57 KB |
| `index-*.js` (entry) | 1.82 KB |
| `vendor-react/query/motion/form/map/charts` (6 stubs) | 0.04 KB each |
| `index-*.css` | 238.56 KB |

The 6 empty vendor stubs and the tiny entry chunk strongly suggest **chunk splitting is broken** — 6,569 modules transform but only ~144 KB of JS reach `dist/`. Either:
- Vite config `manualChunks` no longer matches actual import graph, or
- A preserveModules / tree-shake setting is swallowing content.

This is **not a regression from Phase 1+2** (the earlier pre-cleanup build showed the same anomaly). Flagging here because any serious «reduce bundle by X%» goal must first fix this — current numbers are meaningless. **Recommendation:** separate task — add `rollup-plugin-visualizer` to the build and debug the `manualChunks` function.

### 7.1 `@radix-ui/react-toast` + shadcn toast system — 🟡 Medium risk, clean refactor
- 3 files still import `useToast` from `@/hooks/use-toast`:
  `src/pages/owner/SalesDealDetail.tsx`, `src/components/owner/contacts/CreateContactSheet.tsx`, `src/components/owner/contacts/EditContactSheet.tsx`
- The active toast system is **Sonner** (mounted in `App.tsx:11`).
- Action: migrate those 3 files from `useToast` → `sonner`'s `toast()`, then delete `use-toast.ts`, `toast.tsx`, `toaster.tsx`, `@radix-ui/react-toast`.
- Estimated win: ~4 KB bundle + 1 dep.

### 7.2 Edge Functions — 🟠 High risk without further audit
68 Edge Functions are not invoked from the frontend. Categorization:

| Category | Count | Action |
|---:|---:|---|
| Cron-scheduled (e.g. `daily-reconciliation`, `monthly-owner-statements`) | 11 | Keep — verify cron schedules in Supabase dashboard before any delete |
| Inbound webhooks (`stripe-webhook`, `auth-email-hook`, `whatsapp-incoming-webhook`) | 5 | Keep — external-party-invoked |
| Background AI / auto-triggers (`ai-owner-nurture`, `post-order-autopilot`) | 22 | Keep — invoked by DB triggers / cron |
| External sync (`airbnb-sync`, `ota-scrape`, `rentals-united-sync`) | 9 | Keep — scheduled |
| Checkout variants (`create-flowers-checkout`, `create-pet-checkout`, `create-event-checkout`, etc.) | 12 | **Investigate** — some verticals may not be live yet (flowers/bloom flagged as a bug in `CLAUDE.md` RE Audit Findings) |
| Utility (`get-mapbox-token`) | 1 | **Likely dead** — Mapbox was removed from the app (only DB field `mapbox_bounds` remains as a column name) |
| Other (`task-reminders`, `visa-expiry-reminders`, `user-analytics-api`, ...) | 8 | Keep — unclear trigger path |

**Recommendation:** before deleting any function folder, do one of (a) check `pg_cron` schedules, (b) grep for cross-function invocations inside `supabase/functions/*/index.ts`, (c) confirm with ops that the function is undeployed. This is not safe to automate.

### 7.3 Unrouted pages — 🟢 Low risk once re-verified
22 `.tsx` files under `src/pages/` are not referenced in `AnimatedRoutes.tsx`. After cross-checking with `APP_ROUTES` constants and `pageRegistry.ts`, the real unrouted survivors (not yet deleted in Phase 2) are:

Knip did not flag them because they are imported elsewhere (likely from other pages that are also unrouted). Need a two-hop reachability analysis before deletion. Estimated ~3,000–5,000 LOC.

- `docs/` folder: 473 KB (some stale, e.g. `MIGRATION_PLAN.md` now marked ON HOLD; old session summaries)

### 7.5 Duplicate components — 🟡 Medium effort

### 7.6 Auto-generated types (`src/integrations/supabase/types.ts`) — 🔴 Out of scope

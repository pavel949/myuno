# myUNO Brand Book v1.0

## Позиционирование
> «Мы не продаём мечту — мы убираем хаос между вами и жизнью за рубежом.»

**Архетип:** Caregiver × Architect — заботливый, но системный.

## Логотип
- **my** — regular weight, lowercase — личное, человеческое
- **UNO** — semibold, uppercase — система, надёжность
- Без иконки-символа. Бренд = типографика.

## Палитра

### Light Mode
| Роль | HSL | Использование |
|------|-----|---------------|
| Primary | `230 45% 46%` | CTA, активные элементы, ring |
| Background | `40 20% 98%` | Основной фон |
| Foreground | `220 15% 18%` | Текст |
| Muted | `40 10% 94%` | Карточки, разделители |
| Accent Coral | `12 60% 58%` | SOS, срочные уведомления |

### Dark Mode
| Роль | HSL |
|------|-----|
| Primary | `230 40% 58%` |
| Background | `220 12% 6%` |
| Foreground | `40 10% 92%` |

## Типографика
| Уровень | Шрифт | Роль |
|---------|-------|------|
| Body / Sans | DM Sans | Основной текст, UI |
| Display / Headers | Space Grotesk | Заголовки H1-H3 |

## Тон голоса
| ✅ Да | ❌ Нет |
|-------|--------|
| «Ваш трансфер подтверждён» | «Ура! Вы забронировали! 🎉» |
| «Рекомендуем для вашей ситуации» | «ТОП-10 лучших!» |
| Факт → действие → результат | Эмоция → давление → FOMO |

## Иконография
- Lucide — единственный набор, 20px (1.25em) базовый размер
- Иконки внутри `bg-primary/8` контейнеров (40×40, rounded-xl)
- Никаких эмодзи в UI (только в чатах)

## Фотографии
- Tropical Realism — реальные фото, тёплый свет
- Без белых фонов, без PNG-вырезок

## Запрещено
- Неоновые градиенты, glassmorphism как декорация
- Стоковые улыбки, холодные/снежные фото
- Восклицательные знаки в UI-тексте
- Эмодзи в заголовках и кнопках

## Принцип каждого экрана
> «Как этот экран снижает тревогу пользователя прямо сейчас?»

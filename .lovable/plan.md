

# Универсальная карта `/map` — отображение всех локаций на Mapbox

## Проблема

Страница `/map` — заглушка с текстом "coming soon". Mapbox не показывает ничего, потому что карта просто не реализована. При этом рабочие карты уже существуют для отдельных вертикалей (`/property/map`, `/beauty/map`, `/restaurants/map`, `/services/map`), но они изолированы друг от друга.

## Решение

Заменить заглушку в `MapView.tsx` на полноценную универсальную карту, которая:
- Показывает маркеры из всех вертикалей (недвижимость, салоны, рестораны, сервисы)
- Позволяет фильтровать по вертикали через чипы наверху
- Поддерживает query-параметр `?vertical=property` для прямого перехода с фильтром
- Использует существующий компонент `SalonMap` (он уже универсальный — принимает icon и iconBgColor)

## Как это будет выглядеть

```text
+----------------------------------+
| <- Карта           [Фильтры]     |
+----------------------------------+
| [Все] [Жильё] [Красота] [Еда] [Сервис] |
+----------------------------------+
|                                  |
|   Mapbox карта с маркерами       |
|   разных цветов по вертикалям    |
|                                  |
|   🏠 Property (зелёные)          |
|   💆 Beauty (фиолетовые)         |
|   🍽 Restaurants (оранжевые)      |
|   🔧 Services (синие)            |
|                                  |
+----------------------------------+
```

## Технические изменения

### Файл: `src/pages/MapView.tsx` (полная замена)

1. Добавить чтение query-параметра `vertical` из URL
2. Загрузить данные из всех вертикалей через существующие хуки:
   - `usePropertiesForMap` + `transformPropertiesToMarkers` для недвижимости
   - `useSalons` для салонов красоты
   - `useRestaurants` для ресторанов (нужно проверить хук)
   - `useServiceProviders` для сервисов (нужно проверить хук)
3. Объединить все маркеры в один массив `SalonMarker[]` с разными иконками
4. Фильтрация: чипы вертикалей наверху переключают видимые маркеры
5. При клике на маркер — навигация на страницу детали соответствующей вертикали
6. Использовать `SalonMap` как базовый компонент карты

### Данные для маркеров по вертикалям

| Вертикаль | Иконка | Цвет маркера | Источник данных | Навигация при клике |
|-----------|--------|--------------|-----------------|---------------------|
| Property  | 🏠    | bg-emerald-600 | `usePropertiesForMap` | `/property/{id}` |
| Beauty    | 💆    | bg-primary     | `useSalons` | `/beauty/salon/{id}` |
| Restaurants | 🍽  | bg-orange-600  | hook ресторанов | `/restaurants/{id}` |
| Services  | 🔧    | bg-blue-600    | hook сервисов | `/services/provider/{id}` |

### Логика фильтрации

- `selectedVertical === 'all'` — показываются все маркеры
- `selectedVertical === 'property'` — только недвижимость
- URL-параметр `?vertical=beauty` автоматически ставит фильтр при загрузке

### Навигация при клике на маркер

Каждый маркер хранит `vertical` в метаданных. При клике определяется маршрут:
```text
property  -> /property/{id}
beauty    -> /beauty/salon/{id}
restaurant -> /restaurants/{id}
services  -> /services/provider/{id}
```

### Без изменений
- Компонент `SalonMap` — используется как есть
- Вертикальные карты (`/property/map`, `/beauty/map` и т.д.) — остаются для специфичной фильтрации
- Edge function `get-mapbox-token` — уже работает
- Хуки данных — используются существующие

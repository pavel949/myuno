
# Боковая панель каталога с категориями и подкатегориями

## Обзор
Создадим профессиональную выдвигающуюся боковую панель (Sheet) для навигации по каталогу маркетплейса. Панель будет содержать иерархический список категорий с раскрывающимися подкатегориями.

## Дизайн панели

```text
┌─────────────────────────────┐
│  ≡  Каталог           ✕    │
├─────────────────────────────┤
│  🔍 Поиск категории...      │
├─────────────────────────────┤
│  🥬 Продукты           ▼    │
│     ├─ Все                  │
│     ├─ Молочка и сыры       │
│     ├─ Мясо и птица         │
│     └─ Овощи и фрукты       │
├─────────────────────────────┤
│  🥤 Напитки            ▶    │
├─────────────────────────────┤
│  🧴 Косметика          ▶    │
├─────────────────────────────┤
│  👶 Детские товары     ▶    │
└─────────────────────────────┘
```

## Основные функции

1. **Кнопка открытия** - бургер-меню на странице каталога и главной странице маркетплейса
2. **Поиск** - фильтрация категорий и подкатегорий по названию
3. **Аккордеон категорий** - раскрывающиеся списки с подкатегориями
4. **Счетчики товаров** - количество товаров в каждой категории/подкатегории
5. **Быстрая навигация** - переход в категорию или подкатегорию по клику

## Технические детали

### Новый компонент: `CategoryDrawer.tsx`

**Использует:**
- `Sheet` (Radix UI) - выезжает слева
- `Accordion` - для раскрытия подкатегорий
- `useMarketplaceCategories` - данные категорий
- `useMarketplaceSubcategories` - данные подкатегорий
- `useMarketplaceProducts` - для подсчета товаров

**Структура:**
```text
src/components/market/
  └── CategoryDrawer.tsx   (новый)
```

### Интеграция

1. **MarketCatalogPage** - добавить кнопку-гамбургер в заголовке
2. **MarketIndex** - добавить кнопку каталога в навигацию

### Визуальный стиль

- Ширина панели: 85% экрана (max 320px)
- Анимация: slide-in-from-left
- Иконки категорий из базы данных или fallback emoji
- Подсветка активной категории/подкатегории
- Плавные переходы для аккордеона

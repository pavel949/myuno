
# Аудит личного кабинета пользователя myUNO

## Резюме анализа

Проведён комплексный анализ структуры личного кабинета (`/profile`) и связанных страниц с точки зрения глобальных best practices и миссии платформы: **сделать жизнь за рубежом простой и удобной**.

---

## Текущая архитектура

| Страница | Путь | Назначение |
|----------|------|------------|
| Profile | `/profile` | Главное меню ЛК |
| Edit Profile | `/profile/edit` | Редактирование аватара, имени, телефона |
| Settings | `/profile/settings` | Персональные данные, адрес, экстренный контакт, медицинская информация |
| My Documents | `/profile/documents` | Хранение паспорта, визы, страховки |
| Wallet | `/wallet` | Баланс, транзакции, кэшбэк, карты |
| Favorites | `/favorites` | Избранные сервисы и товары |
| Bookings | `/bookings` | Список всех бронирований |
| View History | `/view-history` | История просмотров |
| Notifications | `/notifications` | Уведомления |

---

## Соответствие глобальным практикам

### ✅ Реализовано хорошо

| Best Practice | Реализация в myUNO |
|---------------|-------------------|
| **Быстрый доступ к ключевым действиям** | Главное меню с иконками (8 пунктов) |
| **Верификация пользователя** | `EmailVerificationBadge` с резендом подтверждения |
| **Переключение ролей** | `RoleSwitchMenu` — Airbnb-подобное переключение между Guest/Owner/Vendor |
| **Реферальная программа** | `ReferralCard` с кодом и статистикой |
| **Экстренный контакт** | Выделенная секция с предупреждением ⚠️ |
| **Медицинская информация** | Конфиденциальная секция с соответствующей пометкой |
| **Хранение документов** | Полный функционал: паспорт, виза, страховка с отслеживанием срока действия |
| **Кошелёк с кэшбэком** | Баланс, транзакции, лояльность, достижения |
| **История просмотров** | Отслеживание с иконками типов и счётчиком визитов |
| **Privacy-first подход** | Баннеры о GDPR/PDPA в настройках |
| **Pull-to-refresh** | Реализовано на ключевых страницах |

### ⚠️ Требует внимания

| Проблема | Описание | Приоритет |
|----------|----------|-----------|
| **Нет прямой ссылки на "Мои документы"** | Страница `/profile/documents` существует, но не видна в меню Profile.tsx | 🔴 Высокий |
| **Способы оплаты — пустой onClick** | `onClick: () => {}` — ничего не происходит | 🟠 Средний |
| **Нет "Мои поездки" (Trip Hub)** | `/trip/:id` существует, но нет агрегирующей страницы всех поездок | 🟠 Средний |
| **Нет "Мой профиль доверия"** | G-Trust badge логика есть для провайдеров, но не для клиентов | 🟡 Низкий |
| **Хардкод текстов** | Некоторые тексты в EditProfile.tsx только на русском | 🟡 Низкий |
| **Нет onboarding для нового пользователя** | Отсутствует прогресс-бар заполнения профиля | 🟡 Низкий |

## Рекомендации по улучшению

### Фаза 1: Критические исправления (быстрые)

1. **Добавить "Мои документы" в меню Profile.tsx**
   - Иконка: `FileText`
   - Путь: `/profile/documents`
   - Важно для экспатов: паспорт, виза, страховка — критичные для жизни за рубежом

2. **Исправить пустой onClick для "Способы оплаты"**
   - Либо создать страницу `/wallet/cards`
   - Либо убрать пункт из меню

3. **Перевести хардкод тексты в EditProfile.tsx**
   - "Редактировать профиль", "Личные данные", "Сохранение..." → через `language` context

### Фаза 2: Улучшение UX для экспатов

4. **Создать "My Trips" агрегатор**
   - Текущие поездки (из `bookings` где `scheduled_at > now`)
   - Прошлые поездки
   - Quick actions: продлить, повторить, отменить

5. **Прогресс-бар заполнения профиля**
   - "Ваш профиль заполнен на 60%"
   - Checklist: Имя ✅, Телефон ❌, Документы ❌, Экстренный контакт ❌
   - Мотивация: "Заполненный профиль ускоряет бронирования"

6. **Напоминания о сроках документов**
   - Push-уведомления за 30/7/1 день до истечения визы/страховки
   - Ссылка на сервисы продления прямо из уведомления

### Фаза 3: Продвинутые функции

7. **Trust Score для клиентов**
   - Уровень доверия: Новичок → Проверенный → VIP
   - Бейджи: Email verified, Phone verified, Documents uploaded
   - Преимущества: скидки, приоритетная поддержка

8. **Единый таймлайн активности**
   - Объединить: история просмотров + бронирования + транзакции
   - По аналогии с "Activity" в банковских приложениях

9. **Quick Profile Card для шаринга**
   - Генерация "визитки" с QR-кодом для передачи контактов провайдерам

## Итоговая оценка

| Критерий | Оценка | Комментарий |
|----------|--------|-------------|
| Структура и навигация | 8/10 | Логичная иерархия, но "Документы" спрятаны |
| Персонализация | 9/10 | Язык, валюта, локация, персоны — всё есть |
| Безопасность | 8/10 | Экстренный контакт, GDPR/PDPA, верификация |
| Экспат-ориентированность | 7/10 | Документы есть, но нет проактивных напоминаний |
| Соответствие best practices | 8/10 | Близко к Airbnb, но нет Trust Score |

**Общий балл: 8/10** — Личный кабинет качественно реализован и покрывает основные потребности. Для достижения уровня "жизнь за рубежом без стресса" рекомендуется добавить проактивные напоминания о документах и Trust Score.

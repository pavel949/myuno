
# План: Редизайн карточек услуг — круглые аватары провайдеров + улучшенная читаемость

## Анализ текущей ситуации

### Существующие карточки:

| Компонент | Форма | Размер | Назначение |
|-----------|-------|--------|------------|
| `MiniAppCard` | Квадратная с иконкой | 100-120px высота | Навигация по категориям |
| `ServiceCard` | Квадратная 180px | Мелкая | Карусель услуг |
| `ItemCard` | Горизонтальная / Вертикальная | 128px картинка | Листинги |
| `ProductCard` | Квадратная aspect-square | Компактная | Товары маркетплейса |

### Проблемы:
- Карточки услуг (`ServiceCard`) слишком маленькие (180px)
- Нет визуального разделения между услугами и товарами
- Карточки в ленте выглядят однотипно

---

## Предложение: Концепция "Люди vs Вещи"

Создать визуальное разделение на основе **природы контента**:

```text
┌─────────────────────────────────────────────────────────────┐
│  УСЛУГИ = ЛЮДИ                    ТОВАРЫ = ВЕЩИ            │
│                                                              │
│  ┌──────────────────┐            ┌────────────────┐         │
│  │    ┌─────┐       │            │ ┌────────────┐ │         │
│  │    │ 👤  │ Круг  │            │ │   📦       │ │         │
│  │    └─────┘       │            │ │ Квадрат    │ │         │
│  │   Мария К.       │            │ └────────────┘ │         │
│  │   Массаж         │            │  Манго 1кг     │         │
│  │   ⭐ 4.9         │            │  ฿120          │         │
│  └──────────────────┘            └────────────────┘         │
│                                                              │
│  Формат: Круглый аватар           Формат: Квадратный        │
│  провайдера с именем              снимок продукта           │
│  Акцент на ДОВЕРИИ                Акцент на ТОВАРЕ          │
└─────────────────────────────────────────────────────────────┘
```

**Психология:**
- **Круг** — ассоциируется с лицами, доверием, социальными связями
- **Квадрат** — ассоциируется с объектами, стабильностью, каталогом

## Технические изменения

### 1. Новый компонент `ServiceProviderCard`

```typescript
interface ServiceProviderCardProps {
  service: Service;
  variant?: 'featured' | 'compact' | 'horizontal';
  showAvatar?: boolean;
  showLanguages?: boolean;
  showCTA?: boolean;
}
```

### 2. Обновление размеров в `FeaturedServicesGallery`

| Параметр | Было | Стало |
|----------|------|-------|
| Ширина карточки | `w-[180px]` | `w-[260px]` (featured) |
| Высота изображения | `h-24` | `h-32` |
| Padding контента | `p-3` | `p-4` |
| Размер шрифта названия | `text-sm` | `text-base` |
| Аватар провайдера | нет | `w-12 h-12 rounded-full` |

### 3. Адаптивное поведение

- **Desktop (lg+)**: 4 карточки в ряд, вариант "Featured"
- **Tablet (md)**: 3 карточки, горизонтальный скролл
- **Mobile**: 2 карточки + скролл, компактный вариант

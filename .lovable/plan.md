

# UNO AI OS: План трансформации

## Видение

Превратить UNO из платформы с AI-фичами в полноценную AI-операционную систему, где AI автономно управляет привлечением, конверсией, удержанием и ростом -- с минимальным человеческим вмешательством.

---

## Текущий фундамент (что уже работает)

- 13 AI-агентов в "AI Agent Farm" с единым gateway
- Автоматическая сегментация пользователей (lifecycle stages: new -> active -> at_risk -> dormant -> churned)
- 8 lifecycle-шаблонов для автоматических действий
- Vendor Acquisition агент (поиск, скоринг, питч)
- Leads Factory (квалификация лидов)
- Post-order autopilot (отзывы, cross-sell)

---

## Модуль 1: AI Social Media Autopilot

**Цель:** Автоматическая генерация и публикация контента в Telegram-каналы и другие платформы.

**Что будет построено:**

1. **Edge-функция `publish-telegram-post`** -- отправка текста и фото в Telegram-канал через Bot API
2. **Таблица `social_posts`** -- лог всех публикаций (platform, message_id, status, content, scheduled_at)
3. **Таблица `social_content_calendar`** -- AI-генерируемый контент-план на неделю
4. **Edge-функция `ai-content-planner`** -- автоматическая генерация контент-плана на основе:
   - Новых листингов и акций
   - Сезонных событий Пхукета
   - Популярных запросов пользователей
5. **Cron-задача** -- ежедневная публикация по расписанию
6. **UI в Admin MCC** -- Content Calendar с превью и кнопкой "Approve & Schedule"

**Требования:**
- Секрет `TELEGRAM_BOT_TOKEN` для Bot API
- ID канала(ов) для публикации

## Модуль 2: AI Owner Nurturing Pipeline

**Цель:** Автоматическое привлечение и onboarding собственников недвижимости.

**Что будет построено:**

1. **Таблица `owner_prospects`** -- воронка потенциальных собственников (source, status, score, notes)
2. **Edge-функция `ai-owner-nurture`** -- AI-скоринг и генерация персонализированных предложений:
   - Анализ объекта (тип, район, потенциальная доходность)
   - Сравнение с портфелем УК
   - Генерация pitch deck
3. **Триггерные сообщения:**
   - День 0: Welcome + гайд "Как заработать на вашей вилле"
   - День 3: Кейс успешного управления
   - День 7: Приглашение на консультацию
4. **Интеграция в Owner Assistant** -- агент будет знать про nurturing pipeline и предлагать релевантные действия

## Модуль 3: AI Vendor Engagement Autopilot

**Цель:** Расширить существующий `vendor-acquisition` до полного lifecycle.

**Что будет построено:**

1. **Расширение `auto-vendor-nurture`:**
   - Автоматические follow-up цепочки (Day 1, 3, 7, 14)
   - AI-генерация персонализированных pitch-сообщений
   - Отслеживание ответов и конверсии
2. **Vendor Performance Scoring** -- AI анализирует:
   - Качество листингов
   - Скорость ответов
   - Рейтинг отзывов
   - Revenue contribution
3. **Автоматические рекомендации вендорам:**
   - "Обновите фото -- листинги с фото получают +40% кликов"
   - "Добавьте описание на русском -- 70% наших пользователей русскоязычные"

## Модуль 4: Unified AI Command Center

**Цель:** Единый дашборд для мониторинга и управления всеми AI-процессами.

**Что будет построено:**

1. **AI Operations Dashboard** (`/admin/ai-ops`):
   - Статус всех 13+ агентов (active/error/rate-limited)
   - Использование tokens за день/неделю/месяц
   - Конверсии: сколько лидов квалифицировано, вендоров привлечено, постов опубликовано
2. **Pipeline Monitor:**
   - Vendor pipeline: prospects -> scored -> pitched -> onboarded
   - Owner pipeline: prospect -> nurturing -> consultation -> contract
   - User lifecycle: new -> active -> at_risk -> dormant
3. **AI Decision Log** -- все решения AI с возможностью audit:
   - Какие сообщения отправлены
   - Какие скоры присвоены
   - Какой контент сгенерирован

---

## Модуль 5: Cross-Platform Intelligence Layer

**Цель:** AI, который видит все данные и принимает координированные решения.

**Что будет построено:**

1. **Edge-функция `ai-platform-intelligence`** -- "мозг" системы:
   - Ежедневный анализ: какие вертикали растут, какие падают
   - Рекомендации: "Увеличьте рекламу яхт -- спрос вырос на 30% за неделю"
   - Аномалии: "Конверсия ресторанов упала на 50% -- проверьте"
2. **Morning Digest 2.0** -- AI-сводка для команды:
   - Ключевые метрики за 24 часа
   - Автоматические инсайты
   - Список приоритетных действий
3. **AI Revenue Optimizer:**
   - Анализ pricing по вертикалям
   - Рекомендации по динамическому ценообразованию
   - A/B тест предложений

## Технические детали

### Новые Edge-функции (5)

| Функция | Назначение |
|---------|------------|
| `publish-telegram-post` | Публикация в Telegram через Bot API |
| `ai-content-planner` | Генерация контент-плана на неделю |
| `ai-owner-nurture` | Скоринг и nurturing собственников |
| `ai-platform-intelligence` | Ежедневный анализ платформы |
| `auto-social-publish` | Cron для автопостинга по расписанию |

### Новые таблицы (4)

| Таблица | Назначение |
|---------|------------|
| `social_posts` | Лог публикаций в соцсетях |
| `social_content_calendar` | Контент-план с датами публикации |
| `owner_prospects` | Воронка потенциальных собственников |
| `ai_decisions_log` | Аудит-лог решений AI |

### Новые AI-агенты в БД (3)

| Агент | Модель | Назначение |
|-------|--------|------------|
| `content-planner` | gemini-3-flash-preview | Планирование контента |
| `owner-nurture` | gemini-3-flash-preview | Nurturing собственников |
| `platform-intelligence` | gemini-2.5-pro | Стратегический анализ |

### Новые Cron-задачи (2)

| Задача | Расписание | Действие |
|--------|-----------|---------|
| `auto-social-publish` | Каждые 4 часа | Публикация запланированного контента |
| `ai-daily-intelligence` | 07:00 ежедневно | Morning digest + аналитика |

### Секреты

| Секрет | Для чего |
|--------|---------|
| `TELEGRAM_BOT_TOKEN` | Публикация в Telegram |

### Порядок реализации

1. Social Media Autopilot (таблицы + Telegram функция + Content Planner)
2. Owner Nurturing Pipeline (таблица + агент + триггеры)

4. AI Command Center UI (дашборд в админке)
5. Cross-Platform Intelligence (аналитический "мозг")

## Результат

UNO превращается в AI OS, где:
- **Привлечение** вендоров и собственников работает на автопилоте
- **Контент** генерируется и публикуется без участия человека
- **Lifecycle** пользователей управляется AI-триггерами
- **Аналитика** проактивно подсказывает, что делать
- Человек нужен только для **стратегических решений** и **approval** критичных действий

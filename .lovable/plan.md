
# Системный аудит: myUNO vs Airbnb — Short-Term Rental

## Анализ текущего состояния

### Что уже реализовано в myUNO:

| Компонент | Статус | Файлы |
|-----------|--------|-------|
| Политики отмены (5 типов) | Есть в БД | `cancellation_policy_rules` |
| Выбор политики владельцем | Частично | `OwnerRentalTerms.tsx` (только dropdown) |
| Предоплата 10% | Реализована | `DepositPaymentOptions.tsx`, `create-property-deposit-checkout` |
| Залог (Security Deposit) | Есть поле | `owner_properties.deposit_amount` |
| Календарь доступности | Работает | `PropertyBookingCard.tsx`, `PropertyCalendar.tsx` |
| Мгновенное бронирование | Есть | `instant_booking` флаг |
| Чат гость-хозяин | Реализован | `GuestPropertyChat.tsx`, `MessageHostButton.tsx` |
| Правила дома | Есть | `house_rules`, `house_rules_ru` |
| Скидки за срок | Есть | `weekly_discount`, `monthly_discount` |

## Критические пробелы по сравнению с Airbnb

### 1. Host Dashboard — Отсутствующие функции
| Airbnb | myUNO | Приоритет |
|--------|-------|-----------|
| Визуальный редактор политики отмены с preview | Только dropdown | Высокий |
| Оценка доходов при изменении политики | Нет | Средний |
| Сравнение с конкурентами в районе | Нет | Низкий |

### 2. Guest Experience — После бронирования
| Airbnb | myUNO | Приоритет |
|--------|-------|-----------|
| "Your Trip" страница с полной информацией | Только список бронирований | Высокий |
| Cross-sell сервисов после оплаты | Нет на странице успеха | Высокий |
| Детали заезда (код двери, WiFi) | Есть у хозяина, но не показываются гостю | Высокий |
| Иконка поездки в меню | Нет | Средний |

### 3. Booking Flow — Прозрачность
| Airbnb | myUNO | Приоритет |
|--------|-------|-----------|
| Breakdown: цена × ночи + cleaning + service fee | Частично (нет service fee) | Средний |
| Показ полной стоимости ДО оплаты | Есть | OK |
| Дата полного возврата видна сразу | Не вычисляется | Высокий |

### 4. Owner Tools — Управление условиями
| Airbnb | myUNO | Приоритет |
|--------|-------|-----------|
| Шаблоны условий (Studio, Luxury, Budget) | Нет | Средний |
| Быстрое копирование условий между объектами | Нет | Средний |
| Preview как видит гость | Нет | Высокий |

## План реализации

### Этап 1: Улучшение Owner Dashboard (Условия бронирования)

**1.1 Визуальный редактор политики отмены**
- Создать `CancellationPolicySelector.tsx` с карточками политик
- Показывать полное описание, даты возврата на примере
- Добавить preview "Как увидит гость"

**1.2 Шаблоны условий**
- Создать 3 пресета: "Эконом", "Стандарт", "Премиум"
- Возможность применить к любому объекту

### Этап 2: Guest Trip Experience

**2.1 Страница "Моя поездка" (GuestTripDetail.tsx)**
- Детали бронирования с таймлайном (до заезда / во время / после)
- Информация о заезде (код двери, WiFi, правила)
- Контакт с хозяином
- Cross-sell блок: "Подготовьтесь к поездке"

**2.2 Cross-sell после бронирования**
Расширить `PropertyDepositSuccess.tsx`:
- Трансфер из аэропорта
- Аренда авто/байка
- Продукты к приезду
- Цветы/подарки
- Уборка во время проживания

### Этап 3: Прозрачность ценообразования

**3.1 Обновить Price Breakdown**
- Добавить service fee (платформа)
- Показать точную дату бесплатной отмены
- Калькуляция возврата при отмене

### Обновления существующих файлов

| Файл | Изменения |
|------|-----------|
| `OwnerRentalTerms.tsx` | Интеграция CancellationPolicySelector |
| `PropertyDepositSuccess.tsx` | Добавить cross-sell блок услуг |
| `PropertyBookingCard.tsx` | Показать дату бесплатной отмены |
| `BookingTermsCard.tsx` | Рассчитывать refund deadline |
| `crossSellConfig.ts` | Добавить конфиг для post-booking |

### База данных

Таблица `cancellation_policy_rules` уже содержит все необходимые данные:
- `full_refund_hours` — часы до заезда для полного возврата
- `partial_refund_percent` — процент частичного возврата
- `deposit_refundable` — возвращается ли депозит

Нужно добавить:
- `owner_properties.service_fee_percent` — комиссия платформы (по умолчанию 3%)

## Результат

После реализации:

1. **Владельцы** смогут наглядно выбирать и настраивать условия бронирования с preview
2. **Гости** получат Airbnb-like опыт с cross-sell сервисов после бронирования
3. **Платформа** увеличит средний чек за счёт связанных услуг
4. **Прозрачность** — все условия, штрафы и даты возврата видны до оплаты

Уникальное преимущество myUNO: **оффлайн-оплата через WhatsApp** для гостей из регионов без доступа к Stripe (Россия, СНГ).

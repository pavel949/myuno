

# Консолидированный календарь всех объектов УК

## Проблема
Текущий календарь (`/owner/calendar`) работает в режиме "один объект за раз" — нужно переключаться между объектами вручную. Для УК с 5-20 объектами это неудобно: нет общей картины загрузки портфеля.

## Решение
Добавить режим **Multi-Property Timeline** (горизонтальная таймлайн-сетка в стиле Airbnb Host Calendar), где:
- По вертикали — список всех объектов (название + миниатюра)
- По горизонтали — дни (скроллируемая полоса на 30 дней)
- Ячейки показывают бронирования (цветные полосы), задачи (иконки), заблокированные даты

## Изменения

### 1. Новый компонент: `MultiPropertyTimeline.tsx`
- Горизонтально скроллируемая таблица с виртуализацией по `@tanstack/react-virtual`
- Левая колонка — фиксированная (sticky), показывает название объекта и миниатюру
- Ячейки дней: бронирования как горизонтальные полосы (аналогично `AirbnbCalendarGrid`), задачи как иконки, blocked-даты закрашены
- Навигация: кнопки "назад/вперед" по неделям + "Сегодня"
- Клик по ячейке открывает существующий `CalendarDayEventsSheet`

### 2. Новый хук: `useMultiPropertyBookings.ts`
- Загружает бронирования для всех объектов пользователя за видимый период (30 дней)
- Использует один запрос к `property_bookings` с `property_id.in.(...)` 
- Группирует результат по `property_id`

### 3. Обновление `OwnerCalendar.tsx`
- Добавить переключатель режимов: "Один объект" / "Все объекты"
- В режиме "Все объекты" показывать `MultiPropertyTimeline` вместо `AirbnbCalendarGrid`
- Quick Actions и iCal sync скрываются в мульти-режиме (они привязаны к одному объекту)

### 4. Десктоп-оптимизация
- На десктопе (md+) мульти-вид становится режимом по умолчанию
- Левая колонка объектов: ~200px
- Дни: ~45px каждый, горизонтальный скролл

## Техническая реализация

### Данные
- Переиспользуется `usePropertyBookings` с массивом property IDs
- Задачи через `useOperationalTasks` без фильтра propertyId (все задачи)
- Availability через пакетный запрос к `property_availability`

### Визуал
- Бронирования: цветные полосы (каждый объект — свой оттенок или единый primary)
- Задачи: иконки Sparkles/Wrench как в текущем календаре
- Blocked: штриховка или красный фон ячейки
- Сегодня: вертикальная линия-маркер



# Улучшение LifeOS: События, Экстренные ситуации, Общая работоспособность

## Проблемы, обнаруженные при аудите

### 1. События не отображаются на главной
- Компонент `SmartWidget` (погода + события дня + рекомендации) **существует**, но **не подключён** к `Index.tsx` — он просто лежит без использования
- В базе данных 15 активных событий, но все датированы 14-15 февраля. Сегодня (10 февраля) — ни одного события, поэтому даже при подключении виджет показал бы "Нет событий"
- Хук `useTodayEvents` фильтрует строго по `event_date = today` — нет fallback на "ближайшие события"

### 2. LifeOS работает неоптимально
- `LifeOSFocusBar` берёт первую ситуацию по приоритету (`planning`, priority=1) для ВСЕХ пользователей — нет персонализации
- `LifeOSStatusBlock` содержит захардкоженные действия только для 6 из 14 активных ситуаций (arrival, living, health, family, leisure, property) — остальные 8 ситуаций показывают пустой блок
- Нет блока экстренных ситуаций на главной странице

### 3. Нет блока "Экстренные ситуации" на главной
- SOS-страница (`/sos`) полная и качественная (номера, советы, офлайн-кеш)
- Но на главной — только маленькая кнопка "SOS" в HeroBlock
- Нет быстрого доступа к типовым экстренным сценариям: укус, авария, потеря паспорта, без денег

## План реализации

### Фаза 1 — Подключить события на главную + улучшить логику

**Файл: `src/hooks/useTodayEvents.ts`**
- Изменить логику: если сегодня нет событий, показывать ближайшие (`event_date >= today`, limit 3)
- Добавить label "Сегодня" / "Скоро" для отображения

**Файл: `src/pages/Index.tsx`**
- Добавить компонент `SmartWidget` после `QuickActionsGrid` (перед `LifeOSFocusBar`)
- Lazy-load для производительности

### Фаза 2 — Блок "Экстренные ситуации" на главной

**Новый файл: `src/components/home/EmergencyQuickAccess.tsx`**
- Компактный блок с 6 кнопками типовых экстренных сценариев:
  - Здоровье / Укус / Авария / Потерял паспорт / Без денег / Полиция
- Каждая кнопка ведёт на `/sos` с якорем к соответствующей категории (например, `/sos#medical`)
- Кнопка "Позвонить 1155" (Tourist Police) — прямой вызов
- Адаптация под роль: для владельцев добавить "Проблема с жильцом", для всех — "WhatsApp myUNO"
- Дизайн: красный/оранжевый акцент, компактная сетка 3x2, без избыточного текста

**Файл: `src/pages/Index.tsx`**
- Добавить `EmergencyQuickAccess` перед блоком `ConciergeBanner`

### Фаза 3 — Заполнить пробелы LifeOSStatusBlock

**Файл: `src/components/home/LifeOSStatusBlock.tsx`**
- Добавить `CONTEXT_ACTIONS` для всех 14 активных ситуаций:
  - `business` -> Коворкинг, Юрист, Банки
  - `relocation` -> Виза, Жильё, Страховка
  - `pets` -> Ветклиника, Зоомагазин
  - `education` -> Школы, Репетиторы, Курсы
  - `shopping` -> Маркет, Доставка
  - `nightlife` -> Клубы, Рестораны, Такси
  - `sports` -> Залы, Бассейны, Йога
  - `visa_travel` -> Виза, Страховка, Трансфер

### Фаза 4 — Персонализация FocusBar

**Файл: `src/components/home/LifeOSFocusBar.tsx`**
- Вместо слепого `situations[0]`, учитывать:
  - Если есть активный контекст пользователя (`activeCode`) — показывать его
  - Если пользователь — турист без контекста — показывать `arrival` или `planning`
  - Если пользователь — резидент — показывать `living`
  - Если пользователь — владелец — показывать `property`
- Использовать `useUserPersonas()` для определения персоны

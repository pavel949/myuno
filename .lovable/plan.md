

## Цель
Каждая аудитория (по её активной роли) должна сразу видеть **какие конкретные потребности закрывает myUNO для неё** — без маркетинговых обещаний, в тоне «спокойная инфраструктура».

## Что не работает сейчас
- **Кластеры** показывают категории сервисов одинаково для всех (Arrive / Live / Manage / Invest / Legal / Build) — не объясняют *«почему это для тебя»*.
- **Помощник (ConciergeCard)** просто сообщает «приоритет — твоя роль», без ценности.
- **Сигналы** показывают *операционный статус* (виза 48 дней, 6 броней) — это для активных пользователей, а не для понимания «что мне даёт система».
- Нигде нет блока *«как Инвестор вы получаете: 1, 2, 3»*.

## Решение: новый блок `RoleValueMap`

Компактная карточка под `SignalStack`, **до** «Помощника». Для каждой активной роли показывает 3–4 закрытых потребности — формулировки = факт + конкретный механизм.

### Структура (mobile, 384px)

```text
┌──────────────────────────────────────┐
│ ЧТО ЭТО ЗАКРЫВАЕТ ДЛЯ ВАС           │
│ Резидент · Собственник              │
├──────────────────────────────────────┤
│ ● Резидент                           │
│   Виза и TM30 — напоминания и         │
│   подача через юриста партнёра        │
│   Быт — уборка, доставка, ветеринар   │
│   Школы и медицина — каталог с RU    │
│                                       │
│ ● Собственник                         │
│   Объект и календарь в одном месте    │
│   Уборки и обслуживание по расписанию │
│   Отчёт собственнику и выплаты ежемес.│
└──────────────────────────────────────┘
```

- Цветной dot слева = `ROLE_META[persona].color` (визуальная привязка к роли в шапке/сигналах).
- Показываем максимум **2 роли** (primary + secondary). Для остальных — кнопка «Ещё N ролей» открывает `RoleSheet`.
- Если роль одна — 4 пункта, если две — по 3.
- Заголовок секции в едином стиле с другими блоками: `text-[11px] uppercase tracking`.

### Правки в существующих блоках

1. **`ConciergeCard`** — переименовать секцию в «Подсказка» и оставить только то, что реально динамично (без повторения списка ролей). Сейчас он дублирует то, что станет в `RoleValueMap`.
2. **`ClusterGrid`** — добавить под заголовком короткую подпись `«Все направления — отсортированы под ваш профиль»` (одно предложение, спокойно).
3. **`SignalStack`** — без изменений, остаётся операционным статусом.

## Файлы

**Новые:**
- `src/lib/home/roleValueMap.ts` — словарь `ROLE_VALUE_POINTS: Record<UserPersona, { ru: string[]; en: string[] }>` (4 пункта на роль).
- `src/components/home/RoleValueMap.tsx` — компонент, принимает `personas: UserPersona[]`, рендерит до 2 групп.

**Правятся:**
- `src/pages/Index.tsx` — вставить `<RoleValueMap personas={[...activePersonas]} />` между `SignalStack` и `NowInPhuket`.
- `src/components/home/ConciergeCard.tsx` — убрать перечисление ролей из `nudge`, оставить контекстную подсказку («Можно открыть каталог под вашу роль» / «Задайте вопрос помощнику»).
- `src/components/home/ClusterGrid.tsx` — короткая подпись под заголовком.

## Тон копирайта (правила)

- **Только факты:** *«виза — напоминания и подача через юриста-партнёра»*, не *«никогда не пропустите визу»*.
- **Без глаголов-обещаний** (заработайте, получите, экономьте) и без восклицаний.
- **Конкретный механизм** в каждом пункте: *что* + *как* (через кого / на каком условии).
- Длина пункта — 6–10 слов, помещается в 2 строки на 384px.
- RU и EN параллельны по смыслу, не дословный перевод.

## Технические детали

- Без новых зависимостей. Тех же токенов и стилей, что у `SignalStack` / `ClusterGrid`: `rounded-[14px]`, `bg-card`, `border-border`, `text-[12.5px]` для пунктов.
- Чтение `ROLE_META` для цвета dot — уже есть в `roleBlend.ts`.
- Локализация — через `useLanguage()` (`isRu`), словарь хранится прямо в `roleValueMap.ts` (как `SIGNAL_SEED`).
- Доступность: каждая группа — `<section aria-label="...">`, dot = `aria-hidden`.

## Что пользователь увидит

Открыв главную с ролями «Резидент + Собственник», между статусом и помощником появится спокойная карточка, которая прямо отвечает на вопрос *«а что эта система вообще для меня делает?»* — четырьмя строками на каждую его роль. Никаких новых маршрутов, никаких новых зависимостей.

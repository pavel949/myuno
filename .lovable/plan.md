
# Оптимизация каталога: Чёткое разделение Мини-приложений и Провайдеров

## Выявленные проблемы

### 1. Неочевидная разница между типами контента

| Тип | Что это | Куда ведёт | Текущее отображение |
|-----|---------|------------|---------------------|
| **Мини-приложение** | Полноценная вертикаль с booking flow | `/tours`, `/yachts` и т.д. | Обычная карточка |
| **Провайдер** | Конкретный поставщик услуг | `/services/provider/:id` | Обычная карточка |
| **Категория-заглушка** | Категория без данных | Пустая страница | Обычная карточка |

Пользователь не понимает, что его ждёт при клике.

### 2. Таб "Провайдеры" почти пустой

Анализ базы данных показал:
- Большинство категорий имеют `service_count: 0`
- Реальные провайдеры есть только в Home Services (Plumbing, Electrical, AC и т.д.)
- Таб показывает demo-данные, создавая ложные ожидания

### 3. Отсутствие визуальных подсказок

Нет индикации:
- Сколько услуг/товаров в категории
- Есть ли у категории полноценное мини-приложение
- Какой тип контента ожидает пользователя

## Предлагаемое решение

### Этап 1: Визуальное разделение типов контента

Добавить на карточки категорий индикаторы:

```text
+---------------------------+
| 🚢 Яхты          [MINI-APP] |
| 24 яхты доступно           |
| →                          |
+---------------------------+

+---------------------------+
| 🔧 Сантехник    [12 услуг] |
| Home Services              |
| →                          |
+---------------------------+
```

**Визуальные маркеры:**
- **"APP"** badge для мини-приложений с полным функционалом
- **Счётчик** услуг/товаров внутри категории
- **Градиентный фон** для мини-приложений vs обычный для провайдеров

### Этап 2: Умное скрытие пустых категорий

В табе "Провайдеры" показывать только категории с `service_count > 0`:
- Убрать пустые demo-карточки
- Показывать реальных провайдеров или честное сообщение "Скоро"

### Этап 3: Улучшение навигационных подсказок

Добавить на карточки категорий в табе "Все":
```tsx
// Текущее
<button onClick={() => navigate(cat.path)}>
  <Icon /> Яхты
</button>

// Предлагаемое
<button onClick={() => navigate(cat.path)}>
  <Icon /> Яхты
  <Badge variant="secondary">24 яхты</Badge>
  <ChevronRight /> // явная индикация перехода
</button>
```

## База данных: Подсчёт элементов

Для реального подсчёта нужен запрос:

```sql
-- Яхты
SELECT COUNT(*) FROM yachts WHERE is_active = true;

-- Туры  
SELECT COUNT(*) FROM tours WHERE is_active = true;

-- Services по категориям
SELECT category_id, COUNT(*) 
FROM services 
WHERE is_active = true 
GROUP BY category_id;
```

Можно реализовать через:
1. **SQL функцию** `get_category_counts()`
2. **Отдельный хук** `useCategoryCounts()`
3. **Кэширование** результатов на 5 минут

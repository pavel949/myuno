## Критические пробелы (GAP-анализ)

### GAP 1: Шаблоны документов
Нет генерации договоров аренды, актов приёма-передачи, доверенностей. Малый бизнес тратит часы на ручное оформление.

**Решение:** Страница `/owner/documents` с библиотекой шаблонов + подстановка переменных (имя арендатора, даты, суммы) + экспорт в PDF.

### GAP 2: PDF-инвойсы + отправка
Инвойсы существуют в базе, но нет брендированного PDF и отправки клиенту на email.

**Решение:** Кнопка "Download PDF" и "Send Email" на странице инвойсов с использованием `jsPDF` + Edge Function для email.

### GAP 3: Учёт инвентаря / расходных материалов
Нет трекинга расходников (моющие средства, лампочки, постельное бельё). Менеджеры не знают, что закупать.

**Решение:** Таблица `owner_inventory` + страница `/owner/inventory` с минимальными остатками и алертами "Нужно закупить".

### GAP 4: Уведомления и напоминания в UI
Edge Function для напоминаний существует, но нет центра уведомлений в интерфейсе. Пользователь не видит алерты.

**Решение:** Компонент `NotificationCenter` (колокольчик в шапке) + таблица `owner_notifications` + badge с количеством непрочитанных.

### GAP 5: Маркетинг-хаб для малого бизнеса
Есть базовые компоненты (BoostListing, ViewsAnalytics), но нет единого маркетингового центра: промо-акции, скидки, email-рассылки.

**Решение:** Страница `/owner/marketing` с вкладками: Промо-акции, Рассылки клиентам, Аналитика просмотров.

### GAP 6: Дашборд бизнес-аналитики (KPI)
Отчёты есть, но нет сводного дашборда с ключевыми метриками: выручка за месяц, загрузка, маржинальность, top-клиенты.

**Решение:** Виджет `BusinessKPIWidget` на дашборде + полная страница `/owner/analytics` с графиками Recharts.

### GAP 7: Каталог/справочник поставщиков
VendorReviewSheet оценивает поставщиков, но нет самого справочника: список поставщиков, контакты, специализация, средний рейтинг.

**Решение:** Страница `/owner/vendors` со списком, фильтрами по категории, агрегированными оценками.

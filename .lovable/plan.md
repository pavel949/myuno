
# Airbnb-style компактные фильтры с выпадающими списками

## Проблема

Сейчас все фильтры (тип жилья, спальни, компания) расположены в одной горизонтальной строке с прокруткой. Спальни уходят за край экрана и не видны. На Airbnb фильтры реализованы как компактные кнопки-триггеры, каждая из которых открывает выпадающий список.

## Решение

Заменить inline-чипы на компактные кнопки-фильтры в стиле Airbnb. Каждая кнопка показывает категорию и при нажатии раскрывает Popover с вариантами выбора. Все кнопки помещаются в одну строку без прокрутки.

## Визуальная структура

```text
[Тип жилья ▼]  [Спальни ▼]  [Компания ▼]  [Цена ▼]
```

Каждая кнопка:
- В неактивном состоянии: нейтральный фон, текст категории
- При выборе: подсвечивается, показывает количество выбранных или значение (например "2-4 спальни")
- При нажатии: выпадает Popover с grid-сеткой вариантов

## Технические изменения

### Файл: `src/pages/property/PropertySearchPage.tsx`

1. **Заменить горизонтальный scroll-ряд чипов** на flex-строку с 3-4 кнопками-Popover
2. **Тип жилья** — Popover с grid 2 колонки, все типы в одном списке (без разделения на "главные" и "ещё")
3. **Спальни** — Popover с grid-сеткой кнопок (Студия, 1, 2, 3, 4, 5+, 6+, 8+, 10+, 12+), мульти-выбор
4. **Компания** — остаётся как есть (уже Popover)
5. Каждая кнопка-триггер показывает краткую сводку выбранного (например "Villa, Condo" или "3+ спальни")

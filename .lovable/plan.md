

# Улучшение текстов LifeOS: аудит и рекомендации

## Общий диагноз

Тексты в целом написаны грамотно, но есть системные проблемы:

1. **Однообразие формулировок** — слишком много "Мы поможем", "Мы подобрали", "Мы знаем". Создаёт ощущение шаблонности.
2. **Слабые recognition-блоки** для второстепенных ситуаций — коротко и формально ("Ищете, куда сходить?", "Нужно что-то купить?").
3. **Нет эмоциональной дифференциации** — "Спорт", "Шоппинг", "Ночная жизнь" звучат одинаково сухо.
4. **Несоответствие тону бренда** — бренд-бук говорит "Факт → действие → результат", а тексты местами скатываются в "маркетинговый консалтинг" ("Мы работаем только с проверенными...").

## Принципы переработки текстов

1. **Факт, а не вопрос** — не "Ищете X?" а "X — вот как это работает"
2. **Ситуация, а не мы** — фокус на контексте пользователя, не на сервисе
3. **Конкретика, а не обещания** — "Все провайдеры проверены" вместо "Мы знаем лучшие"
4. **Один тон** — спокойный, экспертный, без маркетинговых клише

Изменения затронут только данные в базе (SQL UPDATE) и одну строку в `LifeFlowPage.tsx`. Код компонентов не меняется.

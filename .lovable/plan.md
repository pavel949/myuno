## 2. Критические пробелы для исправления

### 2.1 Переводчик в чате (ВЫСОКИЙ ПРИОРИТЕТ)

**Проблема:** Гость из России пишет хозяину-тайцу или наоборот. Нет возможности перевести сообщение.

**Решение Airbnb:** Кнопка "Translate" под каждым сообщением. Перевод на язык пользователя.

**План реализации:**
- Добавить кнопку перевода под каждым сообщением в чате
- Использовать существующий `ai-translate` edge function
- Кэшировать переводы в localStorage
- Показывать оригинал + перевод

```
┌─────────────────────────────────────────┐
│ Хозяин: สวัสดีครับ ยินดีต้อนรับ           │
│ [🌐 Перевести]                          │
├─────────────────────────────────────────┤
│ После клика:                            │
│ Хозяин: สวัสดีครับ ยินดีต้อนรับ           │
│ ───────────────────                     │
│ 🌐 Здравствуйте, добро пожаловать!       │
│ [Показать оригинал]                     │
└─────────────────────────────────────────┘
```

### 2.2 Улучшения UX чата

**Проблемы:**
- Нет индикатора "печатает..."
- Нет визуального подтверждения "доставлено/прочитано"
- Нет возможности отправить фото в чат

**План:**
- Добавить Realtime presence для "печатает..."
- Использовать существующее поле `read_at` для галочек
- Добавить загрузку изображений через Storage

### 2.3 Калькулятор возврата при отмене

**Проблема:** Гость не видит точную сумму возврата при отмене.

**Решение:**
- В `BookingTermsCard` показывать конкретную дату и сумму возврата
- Пример: "При отмене до 10 фев — полный возврат ฿8,500"

## 3. Технические изменения

### 3.1 Новый компонент: ChatMessageTranslation

**Файл:** `src/components/chat/ChatMessageTranslation.tsx`

```typescript
interface ChatMessageTranslationProps {
  messageId: string;
  originalText: string;
  originalLang?: string; // auto-detect
  targetLang: 'ru' | 'en' | 'th';
}

// Логика:
// 1. Кнопка "Перевести" под сообщением

// 3. Кэширование в localStorage: `chat-translation-${messageId}`
```

## 4. UX-улучшения

### 4.1 Индикатор статуса сообщения

```
✓  — отправлено
✓✓ — доставлено  
✓✓ (синие) — прочитано
```

### 4.2 Автоопределение языка

- Если сообщение на Thai — показывать кнопку "Перевести на RU/EN"
- Если на русском — показывать "Translate to EN/TH"

### 4.3 Горячие клавиши в чате

- Enter — отправить
- Shift+Enter — новая строка (уже работает)
- Ctrl+T — перевести последнее сообщение

## 5. План реализации

### Этап 1: Переводчик в чате (Критично)
1. Создать `ChatMessageTranslation.tsx`
2. Обновить `ai-translate` для поддержки Thai
3. Интегрировать в `GuestPropertyChat.tsx`
4. Интегрировать в `PropertyChatWindow.tsx`

### Этап 2: Улучшения UX чата
1. Добавить индикаторы доставки/прочтения
2. Добавить индикатор "печатает..." через Realtime
3. Добавить возможность отправки изображений

### Этап 3: Калькулятор возврата
1. Обновить `BookingTermsCard.tsx` с расчётом дат
2. Добавить интерактивный таймлайн штрафов

## 6. Результат

После реализации:

1. **Гости и хозяева** смогут общаться на разных языках благодаря встроенному переводчику
2. **Прозрачность** — точные суммы возврата при отмене видны до бронирования
3. **Доверие** — индикаторы статуса сообщений повышают уверенность в доставке
4. **Уникальность myUNO** — поддержка Thai + офлайн-оплата для СНГ-рынка

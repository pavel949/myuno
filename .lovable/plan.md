
# План реализации: Разделение Услуги / Товары

## Обзор решения

Реализация явного разделения между **Услугами** (сервисы от провайдеров: юристы, медицина, туры) и **Товарами** (физические продукты из маркетплейса) на главной странице и в системе навигации.

```text
┌─────────────────────────────────────────────────────┐
│                    Главный экран                    │
├─────────────────────────────────────────────────────┤
│  ┌─────────────┐  ┌─────────────────────────────┐  │
│  │  🏷 myUNO   │  │  Hero Banner (без изменений)│  │
│  └─────────────┘  └─────────────────────────────┘  │
├─────────────────────────────────────────────────────┤
│           ┌──────────────┬──────────────┐           │
│           │   УСЛУГИ     │   ТОВАРЫ     │ ← Toggle  │
│           │   (active)   │              │           │
│           └──────────────┴──────────────┘           │
├─────────────────────────────────────────────────────┤
│  ┌─────────────────────────────────────────────────┐│
│  │ [Контент зависит от выбранного режима]         ││
│  │                                                 ││
│  │ Услуги → QuickActionsGrid + Discover sections  ││
│  │ Товары → CategoryRibbon + Product sections     ││
│  └─────────────────────────────────────────────────┘│
└─────────────────────────────────────────────────────┘
```

---

## Этап 1: Создание Toggle-компонента

### Файл: `src/components/home/ContentModeToggle.tsx`

Создание переиспользуемого toggle-компонента для переключения между режимами:

- **Дизайн**: Pill-style toggle с иконками (Briefcase для услуг, ShoppingBag для товаров)
- **Состояние**: Сохранение в localStorage для персистентности между сессиями
- **Анимация**: Framer Motion для плавного переключения индикатора
- **Обратная связь**: Haptic feedback при переключении

```text
┌────────────────────────────────────┐
│  🛠 Услуги  │  🛒 Товары           │
│  ████████████░░░░░░░░░░░░░░░░░░░░  │  ← Активный: Услуги
└────────────────────────────────────┘
```

## Этап 2: Разделение контента главной страницы

### Файл: `src/pages/Index.tsx`

Рефакторинг главной страницы для условного отображения контента:

**Режим "Услуги" (Services):**
- SmartWidget (контекстные действия)
- QuickActionsGrid (сетка быстрых действий)

- MarketCategoryRibbon (лента категорий товаров)
- PopularProductsSection (хиты продаж)
- NewArrivalsSection (новинки)

## Техническая реализация

### 1. ContentModeToggle.tsx

```typescript
type ContentMode = 'services' | 'products';

interface ContentModeToggleProps {
  value: ContentMode;
  onChange: (mode: ContentMode) => void;
}
```

Используемые библиотеки:
- `framer-motion` для анимации индикатора
- `localStorage` для сохранения предпочтения
- `triggerHaptic` для тактильной обратной связи

### 2. Index.tsx - Условный рендеринг

```typescript
const [contentMode, setContentMode] = useState<ContentMode>(() => {
  return (localStorage.getItem('myuno-content-mode') as ContentMode) || 'services';
});

// Рендеринг контента на основе режима
{contentMode === 'services' ? (
  <ServicesContent />
) : (
  <ProductsContent />
)}
```

### 3. AdaptiveBottomNav.tsx - Упрощение

Удаление:
- `showMarketPopup` state
- Popup-компонент с категориями
- `handleMarketClick` функция

Добавление:
- Прямая навигация Market → `/market`

## Миграция данных

Не требуется изменений в базе данных.

Текущие таблицы уже разделены:
- **categories** + **services** → Услуги
- **marketplace_categories** + **marketplace_products** → Товары

## Результат

После реализации:

1. **Главная страница**
   - Явный toggle "Услуги / Товары" под поисковой строкой
   - Контент адаптируется под выбранный режим
   - Preference сохраняется между сессиями

2. **Нижняя навигация**
   - Discover → Каталог услуг (`/discover`)
   - Market → Маркетплейс товаров (`/market`)
   - Прямые переходы без промежуточных popup

3. **UX-улучшения**
   - Понятная ментальная модель: "Мне нужна услуга" vs "Мне нужен товар"
   - Быстрый доступ к нужному типу контента
   - Сохранение предпочтений пользователя

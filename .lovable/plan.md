### Что сейчас есть
- **Главная (/)**: Компактный SuperApp-стиль с 10 иконками быстрого доступа
- **/discover**: Поиск услуг с фильтрами (сортировка, цена, категория)
- **/categories**: Полный каталог категорий по группам
- **MiniAppsFAB**: Настраиваемая сетка 3x3 для быстрого доступа

### База данных
- **7 групп категорий**: 33 активные категории
- Все категории привязаны к группам (нет "сирот")

## Бизнес-логика SuperApp: Мировые стандарты

### Эталонные примеры (Grab, Gojek, WeChat)

| Паттерн | Grab/Gojek | Применимость к myUNO |
|---------|------------|----------------------|
| **Главная = Hub** | 8-12 ключевых сервисов на виду | Уже реализовано (10 иконок) |
| **Discover = Marketplace** | Все услуги/товары с поиском и фильтрами | Уже реализовано |
| **Categories = Каталог** | Полный список сервисов по группам | Уже реализовано |
| **Mini-programs** | Легковесные приложения внутри экосистемы | Частично (MiniAppsFAB) |
| **Контекстная персонализация** | Утро = транспорт, Вечер = еда | Частично (SmartWidget) |

### Принципы UX SuperApp

1. **"Progressive Disclosure"** - показывать только нужное в нужный момент
2. **"Single Tap Access"** - любой сервис за 1-2 тапа
3. **"Unified Experience"** - единый дизайн-язык для всех мини-приложений
4. **"Context-Aware"** - адаптация под время, локацию, поведение

## Проблемы текущей реализации

### 1. Дублирование маршрутов
- `/discover` и `/categories` выполняют похожие функции
- Пользователю неясно, куда идти за полным списком сервисов

### 2. /discover показывает только "услуги" (services table)
Страница `/discover` использует хук `useServices()` который запрашивает таблицу `services`, а не `categories`. Это создаёт путаницу:
- **Categories** = типы сервисов (Яхты, Медицина, Туры)
- **Services** = конкретные провайдеры услуг (Spa "Thai Bliss", Ресторан "Sea View")

### 3. Отсутствие "Service Marketplace"
В SuperApp должен быть единый marketplace где:
- Пользователь видит ВСЕ доступные услуги/товары
- Может фильтровать по категории, цене, рейтингу
- Может искать конкретного провайдера

```text
Главная (/)
    │
    ├── QuickActionsGrid → Прямые ссылки на мини-приложения
    │       ├── /yachts
    │       ├── /restaurants  
    │       ├── /medical
    │       └── ...
    │
    ├── "Ещё" → /discover (ЕДИНАЯ точка входа в каталог)
    │
    └── MiniAppsFAB → Быстрый доступ к избранным

/discover (UNIFIED SERVICE CATALOG)
    ├── Tabs: [Все] [Категории] [Провайдеры]
    │
    ├── "Все" → Карточки категорий (группами)
    │       → При клике открывает мини-приложение категории
    │
    ├── "Категории" → Дерево категорий с подкатегориями
    │
    └── "Провайдеры" → Конкретные услуги с фильтрами
                (текущий useServices)
```

## Альтернативный вариант (минимальные изменения)

Если полный редизайн избыточен, можно:

1. **Оставить обе страницы**, но чётко разделить:
   - `/discover` = Поиск конкретных услуг/провайдеров
   - `/categories` = Каталог типов сервисов (мини-приложения)

2. **Переименовать кнопку "Ещё"**:
   - Вместо `/discover` вести на `/categories`
   - `/discover` доступна через поиск или фильтр

Этот вариант требует меньше изменений, но менее соответствует паттернам SuperApp.

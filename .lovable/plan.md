

# Встроенный поиск на главном экране Property

## Проблема

Текущий экран `/property` (PropertyIndex) содержит нефункциональную строку поиска — она работает как кнопка-ссылка на `/property/search`. Пользователь вынужден делать лишний переход, чтобы задать даты, район и количество гостей. Это противоречит паттерну Airbnb, где строка поиска раскрывается inline.

## Решение

Заменить кнопку-ссылку на полноценный `AirbnbSearchBar` прямо на главном экране `/property`. При клике он открывает fullscreen-модал с табами (Куда / Когда / Кто) — так же, как сейчас работает на `/property/search`. После нажатия "Найти" — переход на `/property/search` с параметрами в URL.

Допуслуги (Трансфер, Авто, Цветы и т.д.) останутся внизу — после карусельных секций — как cross-sell блок.

## Изменения

### Файл: `src/pages/property/PropertyIndex.tsx`

1. **Заменить фейковую строку поиска** (строки 236-244) на компонент `AirbnbSearchBar`
2. **Обработчик поиска**: при нажатии "Найти" — `navigate('/property/search?...')` с параметрами (district, checkIn, checkOut, guests)
3. **Переместить cross-sell сервисы вниз** — после секции "Все объекты", перед нижней навигацией. Сгруппировать их в секцию с заголовком "Может пригодиться" / "You may also need"
4. Убрать кнопку "Фильтры" из секции "Все объекты" (она уже не нужна — поиск на месте)

### Файл: `src/pages/property/PropertySearchPage.tsx`

5. **Считывать URL-параметры** `checkIn`, `checkOut`, `guests` при загрузке страницы и инициализировать `searchParams` state из них — чтобы переход с главной сохранял контекст поиска

## Визуальная структура после изменений

```text
/property (главная)
+----------------------------------+
| <- Жильё          [Аренда|Покупка]|
|                                  |
| [Поиск: Район · Даты · Гости]   |  <-- AirbnbSearchBar (раскрывается inline)
|                                  |
| ── Категории (Beach, Pool...) ── |
|                                  |
| Недавно смотрели  >>>>           |
| Популярное        >>>>           |
| Bang Tao          >>>>           |
| Все объекты (сетка)              |
|                                  |
| ── Может пригодиться ──         |
| [Трансфер] [Авто] [Цветы] ...   |
+----------------------------------+
```

## Что НЕ меняется

- `AirbnbSearchBar` — компонент остаётся без изменений, он уже поддерживает fullscreen-модал на мобильных
- `/property/search` — продолжает работать как полный каталог с фильтрами
- Бронирование (`/property/:id`) — без изменений
- Календари — проверены, работают корректно

## Технические детали

- Импорт `AirbnbSearchBar` и `SearchParams` в `PropertyIndex.tsx`
- Новый обработчик `handleSearch(params: SearchParams)`:
  - Формирует query string из параметров
  - Навигация: `navigate('/property/search?district=...&checkIn=...&checkOut=...&guests=...')`
- В `PropertySearchPage.tsx`: парсинг `checkIn`/`checkOut`/`guests` из `searchParamsUrl` при монтировании
- Cross-sell блок сервисов обёрнут в секцию `SectionHeader` с заголовком

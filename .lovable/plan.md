
# План: Карусель маркетплейса на главной странице (режим Services)

## Текущая ситуация

На главной странице есть **два режима контента**:

| Режим | Что показывается | Маркетплейс |
|-------|------------------|-------------|
| **Products** | `HomeCategoryRibbon` + `HomeProductsSection` | ✅ Полностью представлен |
| **Services** | Туры, СПА, промо-акции | ❌ Маркетплейс отсутствует |

**Проблема:** Когда пользователь находится в режиме "Services" (который стоит по умолчанию), он не видит товары маркетплейса вообще.

---

## Решение

Добавить **промо-карусель маркетплейса** в режим "Services" — визуально привлекательный блок с:
- Хитами продаж (3–4 товара)
- Ярким баннером-заголовком с CTA на /market
- Горизонтальным скроллом как у `RecommendedCarousel`

---

## Что будет реализовано

### Новый компонент: `MarketplacePromoCarousel`

**Визуальный стиль:**
```text
┌──────────────────────────────────────────────────────┐
│  🛒 Свежие продукты              [Смотреть всё →]   │
├──────────────────────────────────────────────────────┤
│ ┌────────┐  ┌────────┐  ┌────────┐  ┌────────┐       │
│ │  📷    │  │  📷    │  │  📷    │  │  📷    │       │
│ │        │  │        │  │        │  │        │ ←───  │
│ │ Молоко │  │ Хлеб   │  │ Овощи  │  │ Мясо   │       │
│ │ ฿85    │  │ ฿45    │  │ ฿120   │  │ ฿299   │       │
│ └────────┘  └────────┘  └────────┘  └────────┘       │
└──────────────────────────────────────────────────────┘
```

**Функционал:**
- Показывает 6–8 популярных товаров
- Горизонтальный скролл с snap-точками
- Кнопка "Добавить в корзину" прямо на карточке
- Клик на товар → `/market/product/:id`
- Ссылка "Смотреть всё" → `/market`

---

## Технические изменения

### 1. Создать `MarketplacePromoCarousel.tsx`

```text
src/components/home/MarketplacePromoCarousel.tsx
├── Использует useMarketplaceProducts({ popularOnly: true })
├── Рендерит ProductCard в горизонтальном скролле
├── Кнопки навигации на hover (как RecommendedCarousel)
└── Мемоизация для производительности
```

### 2. Обновить `Index.tsx`

Добавить карусель в режим "Services" между `PromoBanner` и `QuickAccessChips`:

```text
{/* Promotions */}
<PromoBanner />

{/* NEW: Marketplace Promo */}
<MarketplacePromoCarousel />

{/* Quick Access Chips */}
<QuickAccessChips />
```

## Альтернативный вариант: Компактный баннер

Если полная карусель кажется громоздкой, можно сделать **компактный промо-баннер**:

```text
┌──────────────────────────────────────────────────────┐
│ 🛒 Маркетплейс: 200+ товаров с доставкой за 45 мин  │
│                                     [Открыть →]     │
└──────────────────────────────────────────────────────┘
```

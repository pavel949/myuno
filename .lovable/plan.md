
# Система подсказок следующего шага (Next Step Nudge)

## Проблема

Пользователь выбирает даты в календаре, но не понимает, что делать дальше. По всей платформе отсутствуют визуальные подсказки, направляющие к следующему действию. Это увеличивает отток и снижает конверсию.

## Решение

Создать универсальный компонент `NextStepNudge` -- анимированную подсказку с пульсирующей стрелкой, которая появляется контекстно после завершения действия и указывает на следующий шаг. Интегрировать его в ключевые точки платформы.

## Визуальный стиль

- Компактная полоска (pill) с мягким фоном и анимированной стрелкой (bounce вниз/вправо)
- Текст подсказки + иконка-стрелка с бесконечной bounce-анимацией
- Появляется плавно (fade + slide), исчезает при выполнении действия
- Показывается один раз (через существующий `useHints`)

## Компонент: `NextStepNudge`

Новый файл `src/components/hints/NextStepNudge.tsx`:
- Props: `message`, `direction` (down/right/up), `visible`, `onDismiss`, `className`
- Использует `framer-motion` для анимации появления и bounce-стрелки
- Компактный: одна строка, не занимает много места

## Точки интеграции

### 1. Поиск недвижимости (AirbnbSearchBar)
- **Когда**: пользователь выбрал район(ы) на вкладке "Куда"
- **Подсказка**: "Теперь выберите даты" + стрелка на вкладку "Когда"
- **Когда**: пользователь выбрал даты (checkIn + checkOut)
- **Подсказка**: "Укажите гостей и нажмите Поиск" + стрелка вниз к кнопке

### 2. Страница результатов поиска (PropertySearchPage)
- **Когда**: результаты загружены
- **Подсказка** (первый визит): "Нажмите на карточку для подробностей" -- над списком

### 3. BookingWizard (все вертикали)
- **Когда**: на шаге "Детали" пользователь заполнил обязательные поля
- **Подсказка**: "Всё готово -- нажмите Далее" + стрелка к кнопке "Далее"

### 4. Страница деталей недвижимости
- **Когда**: пользователь выбрал даты в DateRangePicker
- **Подсказка**: "Нажмите Забронировать для продолжения" + стрелка к CTA

## Технические детали

### Модифицируемые файлы

- `src/pages/property/PropertySearchPage.tsx` -- подсказка "нажмите на карточку"
- `src/components/booking/BookingWizard.tsx` -- подсказка "нажмите Далее"

### Структура компонента NextStepNudge

```text
NextStepNudge
  props:
    message: string
    direction: 'down' | 'right' | 'up'
    visible: boolean
    hintId?: string (для show-once через useHints)
    className?: string

  render:
    AnimatePresence ->
      motion.div (fade in/out, slide) ->
        [icon: ChevronDown/Right с bounce-анимацией]
        [text: message]
```

### Анимация стрелки
Используется framer-motion `animate` с бесконечным повтором:
- translateY: [0, 6, 0] для direction='down'
- translateX: [0, 6, 0] для direction='right'
- transition: duration 1s, repeat Infinity

### Логика показа
- В AirbnbSearchBar: `visible` привязан к состоянию (selectedLocations.length > 0 и mobileTab === 'location')
- В BookingWizard: привязан к заполненности обязательных полей на текущем шаге
- Через `hintId` + `useHints` -- показывается только один раз для пользователя



## План: упростить и сделать интуитивным главный экран `/index`

### Контекст
Сейчас на `/index` десять блоков подряд: TopBar → Workspace banner → SignalStack → RoleValueMap → NowInPhuket → QuickActions → Concierge → ActivityFeed → ClusterGrid → TrustFooter. Для нового пользователя это перегружено: непонятно, **что это за сервис**, **с чего начать**, **куда идти за конкретной задачей**. Решения принимать тяжело — слишком много равнозначных карточек.

### Принципы упрощения
1. **Один экран — один вопрос:** «Что вам нужно сейчас?»
2. **Правило 3-х:** не больше 3 крупных решений в первом экране (above the fold).
3. **Понятный вход:** заголовок объясняет «что это», подзаголовок — «для кого».
4. **Прогрессивное раскрытие:** второстепенное прячем под «Показать ещё» / отдельные разделы.
5. **Слова, не иконки:** короткие подписи на русском, без жаргона.

### Новая структура `/index` (сверху вниз)

```
┌─────────────────────────────────────────┐
│ HomeTopBar (логотип, язык, профиль)     │
├─────────────────────────────────────────┤
│ HeroIntro (НОВЫЙ)                       │
│ • H1: «myUNO — всё для жизни на Пхукете»│
│ • Подзаголовок одной строкой            │
│ • Поиск по сервисам (одно поле)         │
├─────────────────────────────────────────┤
│ PrimaryActions (3 карточки, не 8)       │
│ • Найти жильё                           │
│ • Заказать услугу                       │
│ • Мои документы / визы                  │
├─────────────────────────────────────────┤
│ ActiveSituation (если есть)             │
│ • Активный заказ / бронирование         │
│ • Иначе — скрыто                        │
├─────────────────────────────────────────┤
│ AllSections (сворачиваемая)             │
│ • «Все разделы» — кнопка-аккордеон      │
│ • Внутри: ClusterGrid (как сейчас)      │
├─────────────────────────────────────────┤
│ TrustFooter (компактно)                 │
└─────────────────────────────────────────┘
```

### Что убираем с первого экрана
| Блок | Куда переезжает |
|---|---|
| `WorkspaceHomeBanner` | В меню профиля (UserAvatarMenu) |
| `SignalStack` | В `ActiveSituation` (только если есть событие) |
| `RoleValueMap` | Удаляем — заменяет `PrimaryActions` |
| `NowInPhuket` | В отдельный раздел `/discover` |
| `QuickActionsBlended` | Удаляем — заменяет `PrimaryActions` |
| `ConciergeCard` | В правый нижний угол как floating button |
| `ActivityFeed` | В `/account` (личный кабинет) |
| `ClusterGrid` | В аккордеон «Все разделы» |
| `RoleSheet` | Только из меню профиля, не из главной |

### Файлы для правок

**Создать:**
- `src/components/home/HeroIntro.tsx` — заголовок + поиск
- `src/components/home/PrimaryActions.tsx` — 3 главные карточки
- `src/components/home/ActiveSituation.tsx` — обёртка над SignalStack с условием «только если есть»
- `src/components/home/AllSectionsAccordion.tsx` — сворачиваемая обёртка над ClusterGrid
- `src/components/home/FloatingConcierge.tsx` — floating-кнопка концьержа

**Изменить:**
- `src/pages/Index.tsx` — переписать структуру на новую (10 блоков → 5)

**Не трогать:**
- Маршруты, БД, бизнес-логика, остальные страницы, дизайн-токены

### Тон и копирайтинг (RU/EN)
Следуем `mem://style/gov-tone-standard`:
- H1: «myUNO» / тэглайн «Сервисы для жизни на Пхукете»
- Кнопки: номинальные фразы — «Поиск жилья», «Заказ услуги», «Мои документы»
- Никаких «Открой», «Попробуй», «Узнай» — только «Перейти к разделу»

### Что получит пользователь
- **Первый экран помещается в один скролл** на 384px viewport.
- **3 ясных решения** вместо 12 карточек.
- **Поиск** как универсальный fallback, если ни одна карточка не подошла.
- **Концьерж** доступен всегда, но не отвлекает.
- **Опытные пользователи** разворачивают «Все разделы» и видят полную карту.

### Технические детали
- `HeroIntro` использует существующий `useGlobalSearch` (см. `mem://features/search/super-search-architecture-v2`) — поиск по 21+ таблицам.
- `PrimaryActions` использует `Surface variant="card"` (DS2.0 стандарт).
- `AllSectionsAccordion` — на базе `@/components/ui/accordion` (shadcn).
- `FloatingConcierge` — `position: fixed`, не перекрывает `AdaptiveBottomNav` (bottom: 80px).
- Все строки через `useLanguage` с RU/EN ключами.
- Сохраняем `personas` логику для умной сортировки внутри `AllSections`.

### Не входит в этот этап
- Изменение `/discover`, `/account`, кластерных страниц.
- Переработка `AdaptiveBottomNav`.
- A/B тест нового экрана.
- Аналитика кликов по новым блокам (можно добавить отдельной задачей).

### Оценка эффекта
- Время до первого клика: **−40%** (меньше карточек = быстрее решение).
- Bounce rate новых пользователей: ожидаем **−15–20%**.
- Опытные юзеры теряют 1 клик на доступ к кластерам (через аккордеон) — приемлемо.

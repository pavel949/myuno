
# План: AI-Ассистент для владельца недвижимости (Property Owner AI Agent)

## Концепция

Создаём специализированного AI-агента, который:
1. **Знает UNO изнутри** — обучен на всей документации и функционале системы
2. **Консультант по недвижимости** — знает рынок Пхукета, законы Таиланда, практики аренды
3. **Помощник в управлении** — помогает с задачами, бронированиями, финансами
4. **Умный апселл** — тактично предлагает услуги UNO (уборка, ремонт, полное управление)

## База знаний AI-агента

AI будет "обучен" через системный промпт с полной базой знаний:

### 1. Знания о системе UNO

| Раздел | Что знает |
|--------|-----------|
| Dashboard | Все блоки: Портфолио, Операции, Финансы, Сообщения |
| Добавление объекта | 6 шагов, модерация, автоперевод |
| Channel Manager | iCal синхронизация, Airbnb/Booking/VRBO |
| Задачи | Check-in, Check-out, Уборка, Ремонт, Инспекции |
| Финансы | Доходы, 22+ категорий расходов, отчёты |
| Управление | Самостоятельное (10%) vs Полное (30%) |

### 2. Знания о рынке Пхукета

| Тема | Информация |
|------|------------|
| Сезонность | High (ноябрь-апрель), Low (май-октябрь) |
| Средние цены | По типам объектов, локациям |
| Заполняемость | 70-85% в high season, 40-60% в low |
| Конкуренты | Hostaway, Guesty, Lodgify — отличия |

### 3. Законодательство Таиланда

| Тема | Что знает |
|------|-----------|
| Hotel License | Когда нужна, как получить |
| Налоги | Доход от аренды, НДС, ставки |
| Права иностранцев | Владение, ограничения |
| Требования | Регистрация гостей TM30, страховки |

## Интеграция в приложение

### Точки входа

1. **Отдельная страница** `/owner/assistant` — полноценный чат
2. **Плавающая кнопка** на Dashboard — быстрый доступ
3. **Замена текущего OwnerSupportChat** — AI вместо ожидания менеджера

### Контекст пользователя

AI будет получать контекст:
- Количество объектов владельца
- Статус объектов (активны/неактивны)
- Последние бронирования
- Открытые задачи

Это позволит давать персонализированные советы.

## Ожидаемый результат

После реализации владелец сможет:

- ❓ Спросить "Как добавить объект?" → Получить пошаговую инструкцию
- 💰 Спросить "Какие налоги?" → Узнать о ставках и TM30
- 📊 Спросить "Какая заполняемость нормальная?" → Получить данные по рынку
- 🧹 Сказать "Нужна уборка" → AI предложит оформить заявку
- 🏠 Спросить "Стоит ли переходить на полное управление?" → AI объяснит условия и преимущества

AI не заменяет живого менеджера, но берёт на себя 80% типовых вопросов и работает 24/7.


# Реструктуризация главной страницы и Discovery

## Текущие проблемы

### Главная страница (`/`)
1. **Перегружена в верхней части** — 4 персоны + search + trust badges + toggle = слишком много до контента
2. **SmartWidget (Пхукет сегодня) слишком низко** — ключевая ежедневная ценность скрыта за скроллом
3. **InvestorPromoCard не в фокусе** — находится после mode toggle, что снижает конверсию
4. **QuickActionsGrid слишком большой** — 6-8 кнопок для всех персон одновременно
5. **Дублирование CTA** — InvestorPromoCard + OffplanPromoSection + QuickAccessChips с "Invest"

### Страница Discovery (`/discover`)
1. **Плоская структура** — все категории выглядят одинаково важными
2. **Нет визуальной иерархии "App Store"** — mini-apps должны быть hero-элементами
3. **Фильтр по аудитории малозаметен** — лента chips сливается с контентом
4. **Нет "рекомендованного" блока** — персонализация не чувствуется

---

## Новая архитектура главной страницы

### Концепция: "Контекстная воронка"
Каждый блок ведёт пользователя глубже, увеличивая вовлечённость:

```text
┌─────────────────────────────────────────────────────────┐
│  1. HERO BLOCK (компактный)                             │
│     Бренд + Поиск + SOS                                 │
├─────────────────────────────────────────────────────────┤
│  2. PHUKET TODAY (SmartWidget v2)                       │
│     Погода + Quick Stats + Событие дня                  │
├─────────────────────────────────────────────────────────┤
│  3. PERSONA SELECTOR                                    │
│     4 карточки: Турист | Резидент | Владелец | Инвестор │
├─────────────────────────────────────────────────────────┤
│  4. QUICK ACTIONS (6 кнопок, персонализированные)       │
│     Динамически меняются в зависимости от персоны       │
├─────────────────────────────────────────────────────────┤
│  5. CONTENT TOGGLE (Услуги / Товары)                    │
│     + Category Ribbon                                   │
├─────────────────────────────────────────────────────────┤
│  6. FEATURED CONTENT                                    │
│     DiscoveryCarousel (услуги) или ProductsSection      │
├─────────────────────────────────────────────────────────┤
│  7. INVESTMENT CTA (если персона Инвестор)              │
│     InvestorPromoCard ИЛИ OffplanPromoSection           │
├─────────────────────────────────────────────────────────┤
│  8. B2B CHIPS                                           │
│     QuickAccessChips                                    │
└─────────────────────────────────────────────────────────┘
```

## Детальные изменения

### 1. Компактный HeroBlock

**Удаляем из HeroBlock:**
- Trust badges (перенести в SmartWidget)
- 4 персоны (вынести в отдельный блок)

**Оставляем:**
- Бренд (компактный)
- Поиск (InlineSearch)
- SOS кнопка

**Результат:** Высота блока уменьшается с ~350px до ~100px

## UX-хаки для нового приложения

### 1. Stagger Animation
```typescript
// Блоки появляются последовательно с задержкой 0.05s
const container = {
  show: {
    transition: { staggerChildren: 0.05 }
  }
};
```

### 2. Gradient Border для приоритетных элементов
```css
/* InvestorPromoCard, TopApps */
.priority-card {
  background: linear-gradient(var(--background), var(--background)) padding-box,
              linear-gradient(135deg, var(--primary), var(--accent)) border-box;
  border: 2px solid transparent;
}
```

### 3. Персонализированные микро-тексты
- Если турист: "Привет, путешественник!"
- Если резидент: "Привет, сосед!"
- Если инвестор: "Добро пожаловать, инвестор"

### 4. Progress Indicators
- На SmartWidget: кольцо "сколько Пхукета вы открыли" (gamification)
- На Discovery: "Популярно сейчас 🔥" badge

### 5. Skeleton States
- Все блоки с правильными placeholder'ами
- Pulse animation для ощущения "загружается"

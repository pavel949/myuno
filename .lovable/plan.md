
# Редизайн Discover: из "простыни иконок" в красивый каталог услуг

## Проблема

Сейчас Discover — это однообразная сетка иконок 3x4 без визуальной иерархии. Все группы выглядят одинаково: заголовок + одинаковые круглые иконки. Нет акцентов, нет featured-элементов, нет цветовой навигации. Это "простыня", а не витрина суперапп-платформы.

## Решение

Полная переделка страницы с тремя уровнями визуальной иерархии:

```text
1. [Sticky Search]         -- остаётся, немного улучшаем
2. [Featured Strip]        -- NEW: горизонтальная карусель 3 главных сервисов (крупные карточки)
3. [Group: Transport]      -- карточки-строки с иконкой + описанием
4. [Group: Home & Living]  -- то же
5. [Group: Leisure]        -- то же  
6. [Group: Health]         -- то же
7. [Group: Premium]        -- акцентированный блок (золотой фон)
```

---

## Блок 2: Featured Strip (новый)

Горизонтальная карусель из 3-4 "hero" карточек для топовых сервисов. Каждая карточка:
- Высота ~120px, ширина ~75% экрана
- Градиентный фон (уникальный для каждого сервиса)
- Крупная иконка + название + краткое описание
- snap-scroll для мобильного

Сервисы: Property, Experiences, Yachts, Transport

---

## Блоки 3-6: Группы услуг — новый формат

Вместо сетки 3x4 одинаковых иконок, каждая группа становится секцией с:

1. **Заголовок группы** — с цветной иконкой вместо эмодзи, и описанием
2. **Список услуг** — вертикальный, каждая услуга как строка:
   - Иконка в цветном круге (градиент по вертикали)
   - Название (font-medium, text-sm)
   - Шеврон справа (ChevronRight)
   - Разделитель между строками
   - Стиль: похоже на iOS Settings-list

Этот формат:
- Легче сканировать взглядом (вертикальный список vs сетка)
- Понятнее для пользователя (текст крупнее, не 11px)
- Профессиональнее (как Revolut/Grab)

---

## Блок 7: Premium группа — акцентированная

Последняя группа (Concierge + SOS) получает выделенный фон:
- `bg-gradient-to-r from-amber-50 to-yellow-50` (light)
- `dark:from-amber-950/20 dark:to-yellow-950/20`
- Бордер `border-amber-200`
- Это визуально отделяет премиум-услуги

## Технические детали

### Файлы

| Файл | Действие |
|------|----------|
| `src/pages/Discover.tsx` | Полная переработка layout |

Всё делается в одном файле — Discover.tsx. Компоненты инлайнятся, так как используются только здесь.

### Ключевые изменения в Discover.tsx:

1. **Featured карусель** — горизонтальный scroll-container с 3-4 карточками hero-размера
2. **Группы** — формат list-rows вместо grid:
   - Каждый item: flex-row с иконкой, label, chevron
   - Группа обёрнута в Card (rounded-2xl, border, shadow-sm)
   - Внутри: divide-y для разделителей
3. **Premium группа** — отдельный стиль с акцентным фоном
4. **Поиск** — фильтрация работает как раньше, только по новому layout
5. **Убираем эмодзи** — заголовки групп получают Lucide-иконки через resolveIcon

### Что НЕ меняется:
- Данные (VERTICAL_GROUPS, VERTICALS)
- Роуты
- MiniAppLayout обёртка
- Логика поиска
- resolveItem функция

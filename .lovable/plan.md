
# Аудит и оптимизация свайпа на главной странице

## Диагностика: выявленные проблемы

### Проблема #1: PromoBanner использует примитивную логику свайпа
**Текущая реализация** (`src/components/home/PromoBanner.tsx`):
- Использует кастомные обработчики `onTouchStart`, `onTouchMove`, `onTouchEnd`
- Переключение слайда происходит только после того, как палец поднят
- Нет визуального отклика во время движения пальца
- Отсутствует инерция и плавная анимация

**Ощущения пользователя**: Баннер "залипает", не реагирует на движение в реальном времени

### Проблема #2: PullToRefresh может конфликтовать с горизонтальными свайпами
**Текущая реализация** (`src/components/ui/pull-to-refresh.tsx`):
- При любом движении вниз на верху страницы срабатывает `e.preventDefault()` (строка 64)
- Нет проверки направления свайпа (горизонтальный vs вертикальный)
- Это может "перехватывать" горизонтальные жесты в каруселях

### Проблема #3: Разнородные реализации свайпа
В проекте используются три разных подхода:
1. Кастомные события touch (PromoBanner) - работает плохо
2. Нативный CSS scroll-snap (DiscoveryCarousel) - работает хорошо
3. Библиотека Embla (carousel.tsx) - работает отлично, но не используется

## План исправления: "Летающий свайп"

### Этап 1: Переработка PromoBanner на Embla Carousel

**Файл**: `src/components/home/PromoBanner.tsx`

**Изменения**:
1. Заменить кастомную логику на компоненты `Carousel`, `CarouselContent`, `CarouselItem`
2. Добавить плагин `embla-carousel-autoplay` для автопрокрутки
3. Сохранить текущий дизайн (градиенты, иконки, точки навигации)
4. Добавить callback `onSelect` для синхронизации индикаторов

**Результат**:
- Баннер будет следовать за пальцем в реальном времени
- Плавная инерция и "отскок" при достижении края
- Автопрокрутка с паузой при касании

### Этап 2: Улучшение PullToRefresh для предотвращения конфликтов

**Файл**: `src/components/ui/pull-to-refresh.tsx`

**Изменения**:
1. Добавить отслеживание startX координаты
2. Проверять направление жеста: `Math.abs(deltaY) > Math.abs(deltaX)`
3. Вызывать `preventDefault()` только при вертикальном свайпе
4. Добавить "мертвую зону" (5-10px) перед определением направления

**Результат**:
- Горизонтальные свайпы в каруселях не будут блокироваться
- Pull-to-refresh будет работать только при явном вертикальном жесте

### Этап 3: Оптимизация анимаций

**Файл**: `src/components/home/PromoBanner.tsx`

**Изменения**:
1. Использовать CSS `will-change: transform` для слайдов
2. Добавить `touch-action: pan-y` на контейнер карусели
3. Оптимизировать ререндеры через `useMemo` для данных промо

### Логика PullToRefresh (улучшенная)

```text
TouchStart:
  → Запомнить startX, startY
  → isDeciding = true

TouchMove:
  → if isDeciding AND движение > 5px:
      → if |deltaY| > |deltaX|: isVertical = true
      → else: isHorizontal = true, отменить PullToRefresh
  → if isVertical AND deltaY > 0 AND atTop:
      → e.preventDefault()
      → показать индикатор
```

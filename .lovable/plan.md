

# Оптимизация Owner-модуля: от декларативного текста к конкретному функционалу

## Проблема

Страница **OwnerLanding.tsx** (440+ строк) содержит преимущественно маркетинговый контент:
- 6 карточек "Преимущества для собственников" — общие фразы
- 4 карточки "Для управляющих компаний" — абстрактные обещания  
- 3 варианта сотрудничества — описательные блоки
- Статистика "500+ объектов" — не персонализирована
- Два CTA-блока "Полное управление" — дублируют друг друга

**Результат:** Пользователь видит рекламу вместо инструментов.

---

## Целевая аудитория и её реальные потребности

**Собственник недвижимости на Пхукете хочет:**
1. Быстро узнать: сколько заработал за месяц?
2. Кто сейчас живёт в моём объекте?
3. Какие задачи на сегодня? (уборка, заезд/выезд)
4. Есть ли новые бронирования?
5. Как связаться с управляющим/гостем?
6. Добавить расход одним тапом

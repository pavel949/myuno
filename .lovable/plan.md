

# Рекомендация: 5 ключевых доработок для myUNO Property

На основе проведённого аудита, вот **5 изменений с максимальным влиянием на конверсию**, отсортированных по приоритету.

---

## 1. Карусель фото на карточках листинга

**Проблема**: Сейчас карточка показывает одно фото. Пользователь не может оценить объект без перехода на детальную страницу — это снижает CTR.

**Решение**: Заменить статичное изображение в `PropertyListingCard` на свайпируемую карусель с dots-навигацией (используя уже установленный `embla-carousel-react`).

**Влияние**: +15-20% CTR на карточках (индустриальный бенчмарк).

---

## 2. Рабочий Wishlist (сердечко) на карточках

**Проблема**: Кнопка Heart на карточке сейчас ничего не делает — `onClick` просто вызывает `e.stopPropagation()`. Это ломает доверие пользователя.

**Решение**: Заменить пустую кнопку на существующий компонент `FavoriteButton` (из `src/components/uno/FavoriteButton.tsx`), который уже подключён к `useUserCollections`.

**Влияние**: Минимальная работа, максимальная польза — функциональность уже готова, нужна только интеграция.

---

## 3. Секция «Hosted by» на странице объекта

**Проблема**: На детальной странице нет информации о хосте/управляющей компании. В Airbnb это ключевой элемент доверия.

**Решение**: Создать компонент `HostProfileSection` — аватар, имя, дата регистрации, языки, значок "Суперхост". Данные частично доступны в `rental_terms` (manager_name, host_languages) и через `provider_id` в таблице `profiles`.

**Влияние**: Критический trust-элемент, влияет на решение о бронировании.

---

## 4. Секция отзывов на странице объекта

**Проблема**: Компонент `ReviewsSection` существует, но **не подключён** к странице объекта. Отзывы — второй по важности фактор принятия решения после фото.

**Решение**: Интегрировать существующий `ReviewsSection` в страницу `/property/:id`. Добавить рейтинг по категориям (расположение, чистота, соотношение цена/качество) как в Airbnb.

**Влияние**: Прямое влияние на конверсию бронирований.

---

## 5. Inline-карта на странице объекта

**Проблема**: Сейчас локация показывается только текстом. Airbnb всегда показывает интерактивную карту района.

**Решение**: Добавить компонент с `mapbox-gl` (уже установлен) — маркер на координатах объекта с размытым радиусом для приватности точного адреса.

**Влияние**: Помогает пользователю оценить расположение без внешних инструментов.

---

## Технический план реализации

### Шаг 1: Карусель фото (PropertyListingCard)
- Создать `PropertyImageCarousel` на базе `embla-carousel-react`
- Dots-навигация, touch swipe, lazy loading
- Интегрировать в `PropertyListingCard` вместо одиночного `<img>`

### Шаг 2: Wishlist Heart
- Заменить пустой `<button>` в `PropertyListingCard` (строки 77-82) на `<FavoriteButton itemType="property" itemId={property.id} />`
- Стилизовать под overlay (absolute position, backdrop-blur)

### Шаг 3: HostProfileSection
- Новый компонент `src/components/property/HostProfileSection.tsx`
- Запрос профиля через `provider_id` или данные из `rental_terms`
- Разместить на Detail page между описанием и amenities

### Шаг 4: Reviews на Detail page
- Импортировать существующий `ReviewsSection` в `PropertyDetail`
- Передать `itemType="property"` и `itemId={property.id}`
- Добавить категорийные рейтинги (если нужна миграция — добавить поля в таблицу `reviews`)

### Шаг 5: Inline Map
- Новый компонент `PropertyLocationMap` на базе `mapbox-gl`
- Координаты из полей `latitude`/`longitude` объекта
- Секция "Where you'll be" с описанием района

---

## Порядок реализации

Рекомендую начать с **шагов 1 и 2** (карусель + wishlist) — они дают максимальный визуальный эффект при минимальных затратах и затрагивают только один файл (`PropertyListingCard`).

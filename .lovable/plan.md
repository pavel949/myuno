

# Редизайн десктоп-навигации myUNO

## Проблема

Текущий хедер на десктопе выглядит как стандартный "дешёвый" навбар: плоские текстовые ссылки слева, поисковая строка в центре, куча мелких кнопок-утилит справа. Нет характера, нет архитектурного ощущения. Для платформы-"единорога" это критично.

## Концепция: "Architectural Navigation"

Вдохновение: Stripe, Linear, Notion — спокойная, уверенная навигация с тонкими деталями, которые создают ощущение премиальности.

### Ключевые изменения

**1. Переработка хедера (AppHeader)**
- Логотип myUNO получает тонкую анимацию при ховере (letter-spacing transition)
- Навигационные табы переходят от плоских ссылок к "pill navigation" с мягким индикатором активного таба (animated underline или background pill с transition)
- Поисковая строка становится более элегантной: убираем двойную иконку Search, добавляем мягкий `ring` при фокусе, разделители в виде тонких линий вместо точек
- Утилиты (язык, тема, валюта) группируются в единый компактный блок с разделителем от основной навигации
- Высота хедера увеличивается до 64px для "дыхания"

**2. Навигационные табы с анимированным индикатором**
- Активный таб подсвечивается с помощью animated background pill (framer-motion `layoutId`)
- При переключении pill плавно "перетекает" от одного пункта к другому
- Иконки скрываются в текстовой навигации (только текст — чище)
- Hover-эффект: мягкий `bg-muted/50` с 200ms transition

**3. Поисковая строка**
- Упрощённый дизайн: одна иконка Search слева, текст-placeholder справа
- Тонкая border с hover-shadow
- Клавиатурный shortcut badge `Ctrl+K` справа

**4. Правый блок утилит**
- Визуальный разделитель (тонкая вертикальная линия) между навигацией и утилитами
- Аватар пользователя: добавляем ring-эффект при ховере
- Notification bell: dot-индикатор вместо числового badge

## Технический план

### Файлы для изменения:

1. **`src/components/layout/AppHeader.tsx`** — полная переработка десктопной части:
   - Animated tab indicator с `framer-motion` `layoutId`
   - Упрощённый search pill
   - Группировка утилит с разделителем
   - Убираем иконки из навигации на десктопе (оставляем только текст)

2. Создание **`src/components/layout/DesktopNavTabs.tsx`** — выделенный компонент навигационных табов с:
   - `motion.div` с `layoutId="activeTab"` для анимированного pill
   - Hover/active states
   - Чистые текстовые лейблы

3. **Никаких изменений** в мобильной навигации (AdaptiveBottomNav) — она работает хорошо

### Визуальный результат

```text
+------------------------------------------------------------------+
|  myUNO    Home  Discover  Market  Me    [  Search...  Ctrl+K  ]   |
|           ----                          |  RU  Cart  Bell  [A]    |
|           ^^^^                                                    |
|     animated pill indicator                                       |
+------------------------------------------------------------------+
```

- Чистая типографика без иконок
- Анимированный pill-индикатор активного таба (framer-motion)
- Элегантный поиск с keyboard shortcut
- Сгруппированные утилиты

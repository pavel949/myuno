

# Discover: из портянки в компактный хаб с табами

## Проблема

Текущий формат (вертикальные списки iOS-style) всё ещё "портянка" — 5 одинаковых секций с одинаковыми рядами. Пользователь скроллит бесконечно, нет способа быстро найти нужную группу.

## Решение: горизонтальные табы + компактная сетка

```text
[Sticky Search]
[Tabs: All | Transport | Home | Leisure | Health | Premium]
---
если "All":
  [Featured Strip — без изменений]
  [Compact Grid: все сервисы 3 в ряд, маленькие карточки]
если конкретный таб:
  [Grid только этой группы, 2 в ряд, крупнее]
```

### 1. Горизонтальные табы под поиском

Фильтр-чипы с горизонтальным скроллом:
- "All" (по умолчанию), Transport, Home, Leisure, Health, Premium
- Активный таб: `bg-primary text-white`, остальные: `bg-muted`
- Snap-scroll, компактные pill-кнопки
- Это убирает необходимость скроллить всю страницу — пользователь сразу выбирает нужную категорию

### 2. Режим "All" — компактная сетка 3 колонки

Вместо длинного списка рядов — сетка 3x колонки (как App Store):
- Иконка (IconBadge с градиентом, size md)
- Под ней: название (text-xs, 2 строки max)
- Без ChevronRight, без бордеров между элементами
- Группы разделяются тонким заголовком (label группы, маленький текст)
- Вся страница помещается в ~2 экрана вместо ~5

### 3. Режим конкретного таба — сетка 2 колонки

Когда выбрана конкретная группа:
- Featured strip скрывается
- Карточки крупнее: 2 колонки
- Каждая карточка: иконка + название + короткое описание
- Градиентный фон карточки (уникальный для каждого сервиса)
- Больше визуального веса, меньше элементов на экране

### 4. Premium таб — особый стиль

При выборе Premium:
- Карточки Concierge и SOS с золотым градиентом
- Крупнее обычных (full-width)
- CTA-кнопка прямо на карточке

## Технические детали

### Файл: `src/pages/Discover.tsx` (полная переработка)

Изменения:
1. Добавляется state `activeTab` (string, default 'all')
2. Таб-бар: горизонтальный `flex gap-2 overflow-x-auto` с pill-кнопками
3. При `activeTab === 'all'`: featured strip + flat grid 3-col всех сервисов
4. При конкретном табе: grid 2-col только элементов этой группы
5. Premium таб: отдельный layout с крупными акцентными карточками
6. Поиск: фильтрует по всем табам, при вводе текста табы скрываются и показывается flat-результат

### Что не меняется:
- VERTICAL_GROUPS, VERTICALS, resolveItem
- MiniAppLayout обёртка
- Роуты
- Данные

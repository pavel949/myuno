
# План: Усиление Hero-блока с ценностным предложением и аудиториями

## Проблема текущего Hero

Сейчас заголовок **"Экосистема для жизни за рубежом"** — слишком абстрактный и не доносит:
1. **Уникальность** — почему именно myUNO?
2. **Для кого** — кто целевая аудитория?
3. **Что решает** — какие боли закрывает?

## Технические изменения

### Обновить `HeroBlock.tsx`

1. **Заменить заголовок**:
   - Было: `"Экосистема для жизни за рубежом"`
   - Стало: `"THE ONLY APP YOU NEED ABROAD"` + субтитл

2. **Добавить AudienceCards** — три кликабельные карточки:
   ```typescript
   const audienceCards = [
     {
       id: 'tourists',
       icon: '🏖',
       title: { en: 'Tourists', ru: 'Туристам' },
       services: { en: 'Tours • Transport • Yachts', ru: 'Туры • Транспорт • Яхты' },
       gradient: 'from-sky-500/20 to-blue-500/20',
     },
     {
       id: 'residents',
       icon: '🏠', 
       title: { en: 'Residents', ru: 'Резидентам' },
       services: { en: 'Visas • Medical • Banking', ru: 'Визы • Медицина • Банки' },
       gradient: 'from-emerald-500/20 to-green-500/20',
     },
     {
       id: 'owners',
       icon: '🏢',
       title: { en: 'Owners', ru: 'Владельцам' },
       services: { en: 'Property • Cleaning • Legal', ru: 'Недвижимость • Клининг • Юристы' },
       gradient: 'from-amber-500/20 to-orange-500/20',
     },
   ];
   ```

3. **Стилизация заголовка**:
   - Использовать `text-gradient-gold` для "THE ONLY APP"
   - Субтитл — `text-muted-foreground`

4. **Интерактивность карточек**:
   - При клике: `navigate('/discover?audience=tourists')`
   - Сохранение выбора в `localStorage` для персонализации

## Ожидаемый результат

1. **Мгновенная ясность** — за 3 секунды пользователь понимает:
   - Что это (единое приложение)
   - Для кого (турист/резидент/владелец)
   - Какую проблему решает (всё в одном месте)

2. **Персонализация** — клик по аудитории сразу фильтрует контент

3. **Запоминаемость** — "THE ONLY APP YOU NEED ABROAD" — сильный слоган


# Оптимизация мобильной верстки страницы /discover

## Проблема

На мобильных устройствах (особенно с шириной 320-375px) иконки и текст не помещаются:

| Элемент | Текущее значение | Проблема |
|---------|------------------|----------|
| **Таб "Категории"** | `grid-cols-4` фиксированно | Слишком узкие ячейки для русского текста |
| **Иконки** | `w-12 h-12` (48px) | При 4 колонках + gap-3 = мало места для текста |
| **Текст** | `text-[11px]` | Длинные слова типа "Недвижимость" обрезаются |

```text
Текущий layout (320px экран):
+----+----+----+----+
|48px|48px|48px|48px|  = 192px + 36px gaps = 228px
+----+----+----+----+
      мало места!
```

---

## Решение: Адаптивная сетка

### 1. Таб "Категории" - сетка с респонсивными колонками

```text
Новый layout:
- Mobile (< 400px):  grid-cols-3  → 3 колонки
- Tablet (≥ 400px):  grid-cols-4  → 4 колонки
- Desktop (≥ 640px): grid-cols-5  → 5 колонок
```

### 2. Уменьшение размера иконок на мобильных

```text
До:  w-12 h-12 (48px) - фиксированно
После:
- Mobile:  w-10 h-10 (40px)
- Desktop: w-12 h-12 (48px)
```

### 3. Улучшение переноса текста

- Добавить `break-words` для длинных русских слов
- Уменьшить `gap` между элементами на мобильных

## Технические изменения

### Файл: `src/pages/Discover.tsx`

**CategoryTreeView (таб "Категории"):**

```tsx
// БЫЛО:
<div className="grid grid-cols-4 gap-3">

// СТАНЕТ:
<div className="grid grid-cols-3 xs:grid-cols-4 sm:grid-cols-5 gap-2 sm:gap-3">
```

```tsx
// БЫЛО:
<div className="w-12 h-12 rounded-xl ...">
  <Icon className="w-6 h-6 text-white" />
</div>
<span className="text-[11px] font-medium ...">

// СТАНЕТ:
<div className="w-10 h-10 sm:w-12 sm:h-12 rounded-xl ...">
  <Icon className="w-5 h-5 sm:w-6 sm:h-6 text-white" />
</div>
<span className="text-[10px] sm:text-[11px] font-medium break-words ...">
```

**AllCategoriesView (таб "Все"):**

Этот таб уже использует `grid-cols-2 sm:grid-cols-3`, но можно улучшить:

```tsx
// БЫЛО:
<div className="w-12 h-12 rounded-xl ...">

// СТАНЕТ:
<div className="w-10 h-10 sm:w-12 sm:h-12 rounded-xl ...">
```

## Дополнительные улучшения

1. **Добавить кастомный breakpoint `xs`** в `tailwind.config.ts`:
   ```js
   screens: {
     'xs': '400px',  // новый breakpoint
     'sm': '640px',
     // ...остальные
   }
   ```

2. **Убрать `aspect-square`** с карточек категорий - это заставляет их быть квадратными даже когда текст не помещается

3. **Использовать `hyphens: auto`** для переноса длинных слов типа "Недвижимость" → "Недвижи-мость"

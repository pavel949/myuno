

## Интеграция туристического страхования в myUNO

### Исследование: какие решения доступны

#### 1. Cherehapa (для россиян) -- partners.cherehapa.ru
- **Что это:** Маркетплейс страховок с 2012 года, 18+ страховых компаний (Альфа, Ренессанс, Тинькофф, ERV, Allianz и др.)
- **Партнёрская программа:** Виджет/iframe + реферальные ссылки. Комиссия 40-60% от стоимости полиса
- **Интеграция:** Партнёрский виджет (iframe), который встраивается на сайт. Пользователь заполняет данные и оплачивает прямо в виджете. Полис приходит на email
- **Плюсы:** Мгновенная покупка, знакомый бренд для русских, поддержка на русском, полисы принимаются в тайских больницах
- **Минусы:** Только для граждан РФ/СНГ, виджет не white-label (брендинг Cherehapa)

#### 2. SafetyWing (для международных пользователей)
- **Что это:** "Insurance for Nomads" -- подписочная страховка для цифровых кочевников и путешественников
- **API:** Есть полноценный REST API (documentation.safetywing.com) -- можно создавать полисы программно
- **Партнёрская программа:** ~10% от премии, ambassador-программа
- **Цены:** Nomad Insurance ~$45/4 недели (покрытие до $250K)
- **Плюсы:** Глобальное покрытие, API для интеграции, подписочная модель, популярен среди номадов
- **Минусы:** Нужен API-ключ, интерфейс на английском

#### 3. Тайские компании (Allianz Travel Thailand, AIG Thailand)
- **Allianz Travel Thailand:** Продают online на allianz-assistance.co.th, покрывают иностранцев выезжающих ИЗ Таиланда (не въезжающих)
- **AIG Thailand:** Через checkdi.com, от 170 THB, покрытие emergency medical
- **Проблема:** Тайские компании в основном страхуют тайцев выезжающих за рубеж. Для ВЪЕЗЖАЮЩИХ туристов они не оформляют полисы онлайн

#### 4. Уже в базе myUNO
В `insurance_providers` уже есть 4+ провайдера (AXA Thailand, Pacific Cross, Luma Health, Thai Visa Insurance) -- но это для **резидентов и экспатов** (годовые планы, визовые требования), не для туристов на 1-2 недели.

---

### Рекомендуемая архитектура

Текущие страховые компании в базе (AXA, Pacific Cross) -- это для долгосрочного проживания. Туристическая страховка -- другой продукт. Предлагаю **двухканальную модель**:

```text
+------------------------------------------+
|        myUNO Travel Insurance            |
|       "Застрахуйся перед поездкой"       |
+------------------------------------------+
|                                          |
|  Определяем язык/гражданство пользователя|
|                                          |
|  +----------------+  +-----------------+ |
|  | RU/СНГ         |  | International   | |
|  | → Cherehapa    |  | → SafetyWing    | |
|  |   (iframe)     |  |   (affiliate    | |
|  |   40-60%       |  |    link/API)    | |
|  |   комиссия     |  |    ~10%         | |
|  +----------------+  +-----------------+ |
+------------------------------------------+
```

### Этап 1 (MVP -- можно сделать сейчас)

**Affiliate-ссылки (без API-интеграции):**
- Создать страницу `/insurance/travel` -- "Быстрая туристическая страховка"
- Определить язык пользователя (RU vs EN)
- **RU:** Кнопка "Оформить страховку" → redirect на cherehapa.ru с партнёрским ID (параметры: страна=Thailand, даты поездки)
- **EN:** Кнопка "Get Travel Insurance" → redirect на safetywing.com с affiliate ID
- Привязать к LifeOS `pre_trip_planning` с весом 90 (страховка = must-have)

**Что нужно от вас:**
- Зарегистрироваться в партнёрке Cherehapa (partners.cherehapa.ru) -- бесплатно, без модерации
- Зарегистрироваться в SafetyWing Ambassador (safetywing.com/ambassador)
- Получить партнёрские ID/ссылки

### Этап 2 (после получения партнёрских ID)

**Cherehapa: Виджет (iframe)**
- Встроить партнёрский виджет Cherehapa в iframe на странице myUNO
- Пользователь заполняет форму, выбирает страховку и оплачивает -- всё внутри myUNO
- Виджет содержит брендинг Cherehapa, но визуально встроен в наш интерфейс

**SafetyWing: API-интеграция**
- Подключить SafetyWing API через Edge Function
- Создать нативную форму покупки страховки прямо в myUNO (white-label)
- Полная интеграция: ввод данных → оплата → полис в профиле пользователя

### Этап 3 (масштабирование)

- Добавить сравнение планов (Cherehapa vs SafetyWing vs прямые тайские)
- Интеграция полиса в профиль пользователя (раздел "Мои документы" -- уже есть тип `insurance`)
- Push-уведомления: "Ваш рейс через 3 дня -- оформите страховку!"
- Автозаполнение формы из профиля (имя, паспорт, даты)

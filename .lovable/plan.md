
# Замена "Хиты продаж" на галерею "Чем помочь?"

## Что меняется

Секция "Хиты продаж" (карусель товаров маркетплейса) заменяется на горизонтальную галерею конкретных жизненных решений, адаптированную под активную персону пользователя. Вместо эмодзи каждая карточка использует **Lucide-иконку** внутри тонированного круга с семантическим цветом категории.

## Дизайн карточки

Каждая карточка — компактный горизонтальный блок (~200px ширина):
- Слева: круглый контейнер 40px с Lucide-иконкой на семантическом фоне (например, `bg-rose-100` + `text-rose-600` для медицины)
- Справа: конкретная фраза-действие (1-2 строки, `text-sm font-medium`)
- Стрелка `ChevronRight` справа как индикатор навигации
- Стиль: `bg-card border border-border/40 rounded-2xl`, тактильный отклик при нажатии

## Контент (8-10 карточек)

Адаптивные (по персоне, показываются первыми, ~4 шт.):

**Турист**: Закат на яхте / Тайский массаж рядом / Экскурсия на острова / Трансфер из аэропорта

**Резидент**: Педиатр на дом / Английский лагерь для ребёнка / Продлить визу / Вызвать сантехника

**Инвестор**: Риски новостроек / Сравнить доходность / Юридическая проверка / Управление арендой

**Владелец**: Клининг сегодня / Обслуживание бассейна / Управляющая компания / Ремонт и отделка

Универсальные (после адаптивных, ~4-6 шт.):
- Заказать цветы / Арендовать байк / Найти жильё на месяц / Забронировать ресторан / Вызвать электрика

## Техническая реализация

### 1. Новый файл: `src/components/home/QuickSolutionsGallery.tsx`

- Типизированный массив решений с полями: `id`, `icon` (Lucide component), `iconBg`, `iconColor`, `labelRu`, `labelEn`, `path`, `personas[]`
- Использует `useUserPersonas()` для определения активной персоны
- Использует `useLanguage()` для билингвальности
- Логика: фильтрует по активной персоне, добавляет универсальные, ограничивает до 10
- Горизонтальный скролл через `UnifiedScrollSection` (уже есть в проекте)
- Заголовок секции: "Чем помочь?" / "How can we help?" с иконкой `Sparkles`

### 2. Изменение: `src/components/home/HomeProductsSection.tsx`

- Убрать импорт и рендер секции "Bestsellers" (`ProductSection` с `is_popular`)
- Убрать `popularProducts` useMemo
- Импортировать и вставить `QuickSolutionsGallery` на место "Хитов продаж"
- Секция "Новинки" и CTA "Открыть весь каталог" остаются без изменений

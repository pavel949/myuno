

# План: AI-усиленный поиск с ответами и рекомендациями

## Концепция

Превращаем обычный поиск в "умный ассистент", который:
1. **Ищет по базе** — как сейчас (яхты, рестораны, туры и т.д.)
2. **Отвечает на вопросы** — "Где лучше пляжи?", "Как продлить визу?"
3. **Рекомендует услуги** — на основе вопроса предлагает конкретные услуги из системы

## Шаги реализации

### Шаг 1: Создание Edge Function `ai-smart-search`

Новая функция, которая:
- Получает запрос пользователя
- Анализирует: это поиск или вопрос?
- Для вопросов генерирует ответ через AI
- Связывает ответ с конкретными услугами из БД

**Входные данные:**
```json
{
  "query": "Куда сходить с детьми?",
  "language": "ru",
  "personas": ["tourist"]
}
```

**Выходные данные:**
```json
{
  "type": "ai_answer",
  "answer": "На Пхукете много развлечений для детей...",
  "suggestedCategories": ["tours", "events", "water"],
  "suggestedServices": [
    { "type": "tour", "id": "family-tour-1", "reason": "Семейный тур" }
  ]
}
```

### Шаг 2: Обновление InlineSearch

Добавляем режимы:
- **Обычный поиск** — когда запрос короткий и конкретный ("яхта", "массаж")
- **AI-режим** — когда запрос похож на вопрос ("где", "как", "что посоветуете")

UI изменения:
- Иконка AI рядом с поиском для явного переключения
- Streaming ответа AI в dropdown
- Карточки рекомендованных услуг под ответом

### Шаг 3: Хук `useAISearch`

Новый хук для AI-поиска:
- Определяет тип запроса (поиск vs вопрос)
- Для вопросов вызывает `ai-smart-search`
- Для поиска использует существующий `useGlobalSearch`
- Streaming для плавного отображения ответа

### Шаг 4: Интеграция с персонами

AI учитывает выбранные персоны пользователя:
- Турист спрашивает "что посмотреть" → туры, пляжи, развлечения
- Резидент спрашивает "что посмотреть" → местные события, культура
- Владелец спрашивает → УК, юристы, обслуживание

## Ожидаемый результат

- Пользователь вводит вопрос → получает AI-ответ + карточки услуг
- Пользователь вводит ключевое слово → получает результаты поиска (как сейчас)
- AI учитывает персоны и локацию пользователя
- Ответы на русском и английском языках

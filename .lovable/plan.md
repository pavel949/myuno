## Часть 2: Компактная навигация категорий (MarketIndex.tsx)

### Проблема
Текущий горизонтальный скролл не показывает все категории сразу - пользователь не видит, сколько ещё есть.

### Решение: 2-рядная сетка кнопок

```text
┌─────────────────────────────────────────────┐
│ ≡Каталог │ 🔥Акции │ ⭐Хиты │ 🆕Новинки     │  <- Ряд 1: Быстрые действия
│ 🥬Еда │ 🥤Напитки │ 🧴Уход │ +Ещё 5        │  <- Ряд 2: Топ категории
└─────────────────────────────────────────────┘
```

### Преимущества
- Все ключевые разделы видны сразу без скролла
- Кнопка "Каталог" открывает полную боковую панель
- "+Ещё N" показывает количество оставшихся категорий
- Компактнее и информативнее

### Новые элементы в CategoryDrawer

```text
Компоненты:
├── QuickAccessSection (быстрые ссылки)
│   ├── Deals link → /market/category/deals
│   ├── Popular link → /market/category/popular  
│   ├── New link → /market/category/new
│   └── Wishlist link → /market/wishlist (с бейджем)
│
├── CategoryAccordion (существующий, улучшенный)
│
├── VendorSection (секция для продавцов)
│   ├── Become a Seller → /vendor/onboarding
│   └── Dashboard → /vendor/dashboard
│
└── DrawerFooter
    └── Language toggle RU/EN
```

### Используемые UI компоненты
- `Sheet` (Radix) - выдвижная панель
- `Accordion` - раскрытие подкатегорий
- `Badge` - счётчики товаров
- `Separator` - визуальные разделители
- `ScrollArea` - прокрутка контента

### Хуки данных
- `useWishlist()` - для счётчика избранного
- `useMarketplaceCategories()` - категории
- `useMarketplaceSubcategories()` - подкатегории
- `useMarketplaceProducts()` - подсчёт товаров

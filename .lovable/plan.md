
# План: Оптимизация чекаута до уровня Ozon (3–4 клика)

## Текущая проблема

Сейчас пользователь проходит **5–7 кликов** до завершения покупки:
1. Главная → 2. Категория → 3. Товар → 4. Добавить в корзину → 5. Перейти в корзину → 6. Оформить → 7. Оплатить

## Целевой сценарий (как на Ozon)

**Быстрая покупка**: Товар → "Купить сейчас" → Авто-заполненная форма → Оплата (3 клика)

**Покупка через корзину**: Товар → В корзину → Mini-cart → Чекаут (4 клика)

---

## Что будет реализовано

### 1. Кнопка "Купить сейчас" на карточке товара
- Добавляем кнопку "Купить сейчас" рядом с "В корзину" на странице товара
- Клик сразу переводит на страницу `/market/checkout` с этим одним товаром
- Минует корзину полностью — прямой путь к оплате

### 2. Сохранённые адреса доставки
- Создаём таблицу `user_addresses` для хранения адресов пользователей
- Добавляем поля: адрес, город, имя получателя, телефон, метка ("Дом", "Работа")
- На чекауте — автоматический выбор последнего адреса
- Возможность сохранить новый адрес

### 3. Авто-заполнение из профиля
- Имя и телефон подтягиваются из профиля при оформлении
- Если данные уже есть — форма предзаполнена

### 4. Mini-cart dropdown (опционально)
- При наведении/клике на иконку корзины в хедере — всплывающее превью
- Показывает первые 3 товара, общую сумму
- Кнопка "Оформить" ведёт сразу на чекаут

## Технические изменения

### База данных
```text
┌─────────────────────────────────────────────────┐
│  user_addresses (новая таблица)                 │
├─────────────────────────────────────────────────┤
│  id             UUID PRIMARY KEY                │
│  user_id        UUID REFERENCES auth.users      │
│  label          TEXT (Дом, Работа, Другое)      │
│  recipient_name TEXT                            │
│  phone          TEXT                            │
│  address_text   TEXT                            │
│  city           TEXT                            │
│  postal_code    TEXT                            │
│  country        TEXT DEFAULT 'Thailand'         │
│  is_default     BOOLEAN DEFAULT false           │
│  created_at     TIMESTAMPTZ                     │
└─────────────────────────────────────────────────┘
```

### Компоненты
| Файл | Изменение |
|------|-----------|
| `ProductDetailPage.tsx` | Добавить кнопку "Купить сейчас" с передачей товара в state |

### Хуки
| Хук | Назначение |
|-----|------------|
| `useUserAddresses` | CRUD операции с адресами |

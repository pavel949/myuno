# Админка: аудит дублей и приведение в оптимальное состояние

В админке ~92 страницы. Меню уже сгруппировано по задачам; теперь нужно убрать дубли и неясности. Ничего не удаляется без вашего решения по списку.

## Этап 1. Аудит (без изменений в коде)
Для каждой страницы определить: что показывает, из каких данных, есть ли пункт в меню, сколько раз открывалась (аналитика посещений), работает ли она.
Итог — таблица с решением по каждой странице: **оставить / объединить с … / скрыть / удалить / переименовать**.

Кандидаты в дубли, которые проверю первыми:
- «Центр управления», «Дашборд», «Операции», «Аналитика», «Метрики привлечения», «Метрики инвесторов», «Маркетинг» — пересекающиеся обзоры.
- Каталоги: «Единый каталог», «Мастер-каталог», «Услуги», «Таксономия», «Справочники» + ~20 отдельных страниц вертикалей (салоны, клиники, яхты, цветы, питомцы и т.д.).
- Заявки: «Входящие», «Консультации», «Приём заявок», «Настройки заявок», «Настройки приёма», «Лиды новостроек», CRM, тикеты.
- Новостройки: «Новостройки», «Консоль новостроек», «Проекты», «Застройщики», «Документы проектов».
- Добавление: «Добавить», «Быстрые объявления», «Массовая публикация», «Импорт данных», «Создание контента партнёров».
- Трансферы: «Трансферы», «Операторы», «SLA», «Транспорт».
- Карты: «Настройки Google Maps» и «Диагностика».
- Неясные названия (смесь RU/EN, технические термины) — переименовать по стилю Госуслуг.

## Этап 2. Согласование
Отправлю вам таблицу с моей рекомендацией по каждому пункту. Вы отмечаете, что принять.

## Этап 3. Внедрение принятых решений
- Объединение: одна страница с вкладками вместо нескольких; старые адреса перенаправляются на новую.
- Скрытие: убрать из меню, адрес оставить.
- Удаление: только страниц без данных и использования, с перенаправлением.
- Единые названия в меню и заголовках (RU/EN).
- Проверка: тесты навигации + просмотр экранов на телефоне и компьютере.

## Границы
Рабочие данные, права доступа, база и функции не меняются. Публикации нет без разрешения.

## Технические детали
Источник меню — `src/lib/navConfig.ts` / `src/lib/nav/navigationModel.ts`; маршруты — роутер админки. Объединение через вкладки внутри существующего admin layout; редиректы через `Navigate`. Тест `adminTaskNavigation.test.ts` обновляется под итоговую структуру. Отчёт: `docs/qa/ADMIN_CONSOLIDATION_AUDIT.md`.

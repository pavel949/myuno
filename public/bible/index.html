§ 00

Правила для AI

Hard rules · нерушимы

Это первое, что читает любой AI-ассистент перед задачей. Каждое правило — блокировка merge, если нарушено. Если задача требует нарушить hard-правило — остановись и задай вопрос Павлу. Не предлагай обходные пути.

00.1Hard rules · нельзя нарушать

H · 01
Никаких новых Surface'ов.Их ровно 6: arrive · live · manage · invest · legal · build. Любая фича привязывается к одному из них через URL prefix.
Hard · arch
H · 02
Никаких новых Canvas shells.Использовать MiniAppLayout или существующий OperateShell. Canvas'ов 6: Home · Discover · Operate · Wallet · Me · Admin.
Hard · arch
H · 03
Никаких хардкоженных hex-цветов.Только переменные из src/styles/tokens.css. Каждый PR с #XXXXXX в JSX/CSS блокируется.
Hard · visual
H · 04
Никаких импортов через cluster boundaries.Кластер не может импортировать из другого кластера. Только через shared L4 primitives или L3 services.
Hard · arch
H · 05
AI никогда не auto-execute money moves.Только паттерн intent → user confirms → execute. Confirmation должен показать точную сумму, валюту, получателя.
Hard · money
H · 06
Каждый money-moving экран имеет audit marker.tx_id · ledger_entry_id · timestamp (UTC) видимы в UI. Без этого PR не merge'ится.
Hard · money
H · 07
Каждая новая фича за feature flag.feature_flag:<name> в system_settings. Default = false до GA.
Hard · delivery
H · 08
RU + EN parity 100%.Каждая user-facing строка — обе локали. PR без EN-параллели = блокировка.
Hard · i18n
H · 09
Mobile 375px first.Каждый экран сначала проектируется на 375. Tablet/desktop — варианты, не fallback.
Hard · layout
H · 10
RLS policy на каждой таблице.RLS-disabled таблицы запрещены, кроме явных публичных (с RLS+public-read policy).
Hard · data
H · 11
Никаких placeholder-контента.Empty state с честным «запланировано · Q3 2026» + email capture. Не lorem, не «coming soon!» с эмодзи.
Hard · content
H · 12
Один Supabase client.src/integrations/supabase/client.ts. Никаких новых инстансов. Никакого .schema('v2') — её не существует.
Hard · data
H · 13
JTBD-кластеры не в публичной навигации.10 JTBD (A–J) — это технический тег для AI-роутинга и SEO. Пользователь их не видит.
Hard · arch
H · 14
Никаких console.log в production.Только Sentry. Лог-call'ы убираются перед merge.
Hard · code
H · 15
Strict TypeScript.Никаких any. types.ts руками не редактируется — только supabase gen types.
Hard · code

00.2Soft rules · по умолчанию следовать, требуют обоснования для отступления

S · 01
Один очевидный next step на экране.Если хочется добавить ещё одну primary CTA — задай вопрос: «какой из них critical?»
Soft
S · 02
Цена видна на публичных страницах.«Узнайте стоимость по запросу» — только для HNW Capital (тикет $300K+). Для всего остального — конкретная цифра.
Soft
S · 03
Сервисная риторика, не продуктовая.«Подать TM30», а не «Воспользоваться нашим сервисом TM30». Глагол + объект.
Soft
S · 04
Каждая critical-операция имеет undo / откат.Или явный warning, что отмена невозможна (Land Office submission, signed contract).
Soft

00.3Five-test gate · перед стартом любой задачи

Прогнать через пять вопросов. Менее 3 «да» — отложить задачу.

01 · Revenue
Приносит ли это деньги в Y1?
Прямая выручка или ускорение существующей выручки.
02 · Funnel
Двигает ли по воронке?
Турист → Арендатор → Покупатель → Собственник.
03 · Asset
Создаёт переиспользуемый актив?
Компонент, шаблон, библиотека, дата-схема.
04 · Bandwidth
Поддержит команда из 2?
Pavel + Olga. Если нет — не строить.
05 · Narrative
Укрепляет нарратив для Seed?
«Инфраструктура · доверие · моат».

00.4Anti-patterns · чего не делать никогда

✕ Никогда

Хайп-маркетинг. «🚀 Революционная экосистема ★★★★★», капс, восклицания, «лучший», «уникальный», «революционный».

tone-of-voice.md §5.4 — запрещённая лексика
✓ Всегда

Спокойный факт. «Договор аренды на 12 месяцев. Депозит 2 месяца. Подаём сегодня — селимся завтра.» Конкретные цифры, активные глаголы, без декораций.

tone-of-voice.md §3 — четыре столпа голоса
✕ Никогда

Градиенты в духе стартап-лендинга. Linear-gradient hero, фон с purple→pink, неоновые акценты. Это не Tesla, это инфраструктура.

✓ Всегда

Сплошной цвет + строгая типографика. Deep #0A2240 как фон, paper #F5F4F0 как контраст, amber только как акцент (CTA, ссылка, маркер).

✕ Никогда

Карточка с rounded-l-border accent color. Слева оранжевая полоска шириной 4px, остальное серое. Это AI-slop, видно за версту.

✓ Всегда

Сетка 1px hairline + плоские поверхности. Грид из ячеек с разделителями 1px solid var(--uno-line). Никаких border-left accent stripes.

✕ Никогда

Эмодзи в продуктовых строках. «🎉 Платёж прошёл!», «❌ Ошибка», «👋 Привет!». Это разрушает доверие на сделках $300K+.

✓ Всегда

Функциональные глифы. 🆘 для Emergency и 🏥 для здоровья — допустимы. В остальном — SVG-иконки из системы (lucide / phosphor regular).

PROMPT · Cursor

Готовый промпт для старта задачи: «Перед началом прочитай bible-v2/bible.html §00. Прогони задачу через five-test gate. Если <3 «да» — остановись и сообщи. Используй tokens из tokens.css. Никаких новых Surface'ов, Canvas'ов, hex-цветов. Каждая money-операция — audit marker. RU+EN parity.»

§ 01

Стратегия · в одном экране

PROJECT.md v2.2 → distilled

myUNO — это не маркетплейс и не приложение. Это цифровая инфраструктура государственного класса для иностранцев в Юго-Восточной Азии + доверенный оператор рынка недвижимости. Оба тезиса неотделимы и должны ощущаться в каждом интерфейсе, тексте и решении.

01.1Двойной тезис

Тезис · A
Цифровая инфраструктура гос. класса

Модель — государственный сервисный портал. Не только по дизайну, по принципу ответственности: платформа берёт роль, которую в нормальной стране выполняют институты. Для иностранца на Пхукете таких институтов нет. myUNO заполняет вакуум.

GOV.UKGosuslugie-Estonia+ теплота
Тезис · B
Доверенный оператор и камертон рынка

ClearView (рейтинги off-plan), DueDiligence AI, FloodScore, омбудсмен-статус Павла. Мы устанавливаем стандарты, а не следуем им. Инфраструктурное доверие конвертируется в транзакционное — главный актив платформы.

The EconomistFTS&P / Moody's

01.3Четыре слоя · внутренний разделитель ответственности

Каждая вертикаль принадлежит одному из 4 слоёв. Слой определяет, чем измерять и сколько инвестировать. Пользователь не должен ощущать переход между слоями.

01.4Семь моатов · что нельзя скопировать

M · 01
myUNO как хост на платформе аренды

Единый стандарт check-in, коммуникации, ответственности. Не агрегатор — оператор.

M · 02
Полный жизненный цикл объекта

Покупка → стройка → меблировка → лицензия → PM → аренда → отчёты. 15–20 лет.

M · 03
Омбудсмен-статус Павла

Представитель Правительства Москвы в Таиланде. Институциональное доверие для HNW RU.

M · 04
Партнёрская сеть без заморозки капитала

35 объектов в системе, ~200 готовых. Бренд + канал, не владение.

M · 05
Отношения с девелоперами

Sansiri, Rhom Bho и другие — оперативные соглашения, не «мы знакомы».

M · 06
AI-инструменты без аналогов

ContractAI · DueDiligence AI · FloodScore · ClearView. Асимметрия информации.

M · 07
Физическое присутствие

Офис Cherngtalay · Ольга на земле · сеть подрядчиков. Нельзя создать дистанционно.

Принцип

Главный закон Y1: не строить ничего, что не даёт revenue или не закрывает цикл сделки. Если в задаче < 3 «да» по five-test gate — она ждёт до Seed.
